# P7.3 Bundled Git runtime

**Behaviour.** `scripts/build/build-git.sh` turns the pinned Git tarball into a 9.9 MB relocatable runtime
(ADR-0019) that `02-bundle-git.sh` embeds at `Contents/Resources/git`. It is idempotent: a stamp of version,
hash, architectures and script hash skips the rebuild.

**Failure cases.** Hash mismatch → stop before extracting. Signature check requested without gpg → stop.
A build error → the tail of the per-arch log. A Git that does not run, or whose exec-path is not inside the
app → `02` stops.

**Tests.** `scripts/build/test-bundled-git.sh [--network] [--suite]`: relocation into a path with a space, the
version, exec-path inside the copy, no Rust/Perl/Python, system libraries only, an empty bundled system config
with the global config still respected, init/commit/merge (ort, octopus, resolve)/merge-tree/rebase/
cherry-pick/revert/stash, file:// and local clone, submodule add, HTTPS ls-remote; `--suite` runs all JitKit
tests against it with `GIT_TRACE` (`JIT_TEST_GIT_TRACE`) and scans for missing helpers.
