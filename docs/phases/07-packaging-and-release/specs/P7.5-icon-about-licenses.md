# P7.5 App icon, About, Acknowledgements

**Icon.** `macos/App/AppIcon.icon`, an Icon Composer document: two SVG layers (branch lanes, commit nodes)
with glass and translucency over a teal linear-gradient fill. Xcode 27's `actool` compiles it into
`Assets.car` + `AppIcon.icns` (`CFBundleIconName = AppIcon`). It is an original mark — a lane, a branch arc
and three commits; no Git logo.

**About.** The standard About panel with the version, "build, commit" (`JitSourceCommit`) and a credits line
naming the bundled Git and pointing to Acknowledgements.

**Acknowledgements** (Help menu, palette `help.acknowledgements`): Jit's copyright, a statement that Jit uses
only Apple frameworks and runs Git as a separate program, Git's version, `SOURCE.txt` (source location,
hash, build flags, written offer) and the full GPLv2 text, all read from the bundle. Development builds
without a bundled Git say so instead of showing a placeholder.

**Dependency audit.** JitKit has no third-party Swift packages (no `Package.resolved`); the only bundled
third-party component is Git.
