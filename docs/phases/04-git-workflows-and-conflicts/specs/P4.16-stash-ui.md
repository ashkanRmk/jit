# P4.16 — Stash UI, Stash and Switch, command bar

## Behavior
- Navigator "Stashes" section (expanded by default): `stash@{n}` rows with message, abbreviated age, tooltip
  with branch and untracked note; context menu Apply / Pop / Show Changes / Copy SHA / Drop…; empty state
  "No stashes". The list refreshes from FSEvents on refs.
- Create sheet (Repository ▸ Stash Changes…, ⌥⌘S, command bar Stash; ⌥-click stashes everything now) with
  message, include untracked, keep index, staged only, selected files.
- Command bar Pop pops `stash@{0}`; disabled with "No stashes" when empty.
- Pop/apply with conflicts opens the resolver; the stash is kept and the activity says so.
- Drop → destructive sheet with the SHA and Copy.
- Blocked switch sheet offers Stash and Switch (stash incl. untracked → switch → stash left in place;
  restored if the switch still fails).
- Show Changes opens the stash commit in the inspector (first-parent diff = the stashed tracked changes).

## Deviation
- The inspector shows the stash commit's combined tracked changes, not three sections (staged / unstaged /
  untracked); no graph "Show stashes" toggle (optional in the plan).

## Tests
`StashTests` (core), `stashListLoadsOnceTheRepositoryOpens`; pointer pass: blocked switch → Stash and Switch →
Pop with conflict → resolve → Drop.
