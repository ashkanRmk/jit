# P4.5 — Pull (ADR-0030)

## Behavior
Always fetch (the upstream's remote, cancellable) then one explicit integration, never `git pull`:
- Fast-forward only (default): behind 0 → up to date; ahead > 0 → `NotFastForward(ahead, behind)` without
  running anything; else `merge --ff-only <upstream>`.
- Merge: `merge --no-edit --ff <upstream>` with the profile as author and committer.
- Rebase: `rebase --no-autostash --no-autosquash --no-update-refs <upstream>`; committer is the profile.
The integration step runs in an uncancellable task. Conflicts → `stoppedWithConflicts` (banner). Detached
HEAD or no upstream → explained refusal.

## Tests
`pullFFOnlyFastForwards`, `pullFFOnlyRefusesDivergentWithoutChanges` (fingerprint),
`pullMergeCreatesMergeCommitWithProfileCommitter`, `pullRebaseReplays`,
`pullIgnoresPullRebaseConfigForExplicitChoice`, `pullConflictEntersState`, `pullWithoutUpstreamRefused`.
