# P4.11 — Conflict model (ADR-0031)

## Behavior
- `conflicts()`: `status --porcelain=v2 -z` `u` records (XY + three stage modes/OIDs); attributes:
  symlink (120000), submodule (160000), binary (NUL in first 8 KB, `binary`/`-diff` attribute), > 5 MB,
  non-UTF-8 → `presentation` (text / modify-delete / pick-side / submodule / both-deleted).
- `loadConflict`: stage blobs → private 0700 temp dir → `git merge-file -p --zdiff3 --marker-size=<n>
  -L ours -L base -L theirs` with `n` larger than any marker-like run in the content (so markers already in
  the file are just content) → `ConflictSegment` ranges into one byte buffer. Opening never touches the index.
- `render(choices)`: ours / theirs / both (either order) / base / custom per block; unresolved blocks keep
  markers. Final-line "no newline" is preserved (merge-file adds one before its markers).
- `saveResolution` (hash guard, temp file in the same directory, original mode, `rename(2)`),
  `markResolved` (re-verify hash, `git add`), only on explicit request.
- zdiff3 chosen over diff3 (spike): common prefix/suffix lines move out of the block, so "Both" no longer
  duplicates them; base information is kept.
