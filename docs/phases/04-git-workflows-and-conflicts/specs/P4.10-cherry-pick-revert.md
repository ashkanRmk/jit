# P4.10 — Cherry-pick and revert

## Behavior
- Cherry-pick one or more commits oldest → newest (`rev-list --no-walk=sorted --topo-order --reverse`),
  authors preserved, committer = profile. Merge commits require a mainline (`parents(of:)` lists them).
- Revert (`--no-edit [-m n]`): a new commit by the profile.

## Tests
`cherryPickPreservesAuthorSetsCommitter`, `cherryPickMultiOrder`, `cherryPickConflictContinue`,
`cherryPickAbortRestoresFingerprint`, `cherryPickMergeCommitRequiresMainline`,
`revertCreatesCommitWithProfileIdentity`, `revertConflictAbort`.
