# P4.9 — Merge and rebase

## Behavior
- Merge: `--ff | --no-ff | --ff-only`, `--no-edit` or `-m`; merge commits by the profile (author + committer);
  ff-only refuses divergence without running Git. Preflight `predictMergeConflicts` uses
  `merge-tree --write-tree --name-only` (read-only; Git ≥ 2.38).
- Rebase: `--no-autostash --no-autosquash --no-update-refs <onto>`; clean tracked tree required (Jit checks
  first); `rebasePlan` lists commits and how many are already pushed. Original authors kept.
- Continue (`<op> --continue`, refused while unmerged paths remain), skip (token), abort (token) — the
  operation is detected from the state files.
