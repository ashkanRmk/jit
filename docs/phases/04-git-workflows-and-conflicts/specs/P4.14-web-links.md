# P4.14 — Copy remote links (ADR-0034)

`WebLink.map(remoteURL:target:)`: https, ssh://, scp-like; user and port stripped; `.git` removed;
github.com needs exactly owner/repo; gitlab.com allows nested groups (`/-/commit`, `/-/tree`). Branch names are
percent-encoded per segment. Unknown hosts, local paths and malformed paths → `nil` (no menu item). No network.

Tests: `webLinkCommit` (9 cases), `webLinkBranchEncodesSegments`, `webLinkUnknownHostsNil` (8 cases).
