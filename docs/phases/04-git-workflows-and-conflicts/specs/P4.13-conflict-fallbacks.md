# P4.13 — Non-text conflict fallbacks

## Behavior
`resolveWithSide(path, choice, token)` — the token names path and choice:
- `.ours` / `.theirs`: `checkout --ours|--theirs` + `add` (or `rm` when that side deleted the file).
- `.keepFile` (modify/delete): `add`. `.deleteFile`: `rm`.
- Submodule: explanation + Open in Terminal only (Phase 8). Rename/rename: each path Git reports is listed.

## Tests
`resolveModifyDeleteKeep`, `resolveModifyDeleteDelete`, `resolveBinary(ours|theirs)` (and a token for another
choice is refused), `resolveSymlink`, `submoduleConflictOffersTerminalOnly`, `renameRenamePathsReported`.
