# P2.8 — Branch navigator

Design §3.5. `NavigatorTreeBuilder` (pure): Local / Remote (per remote) / Tags, `/` hierarchy with
single-folder chains collapsed (`feature/ui ▸ tabs`), natural order, current branch first, unborn note,
"No tags", Remote hidden without remotes. `NavigatorViewController`: source-list `NSOutlineView` on the
system sidebar material, filter field (fuzzy subsequence, auto-expand while filtering, restore after),
expand state persisted per tab, ahead/behind badges, `upstream gone` in `status.warning`, pin glyph,
non-commit tags. Click / double-click / ↩ → show in graph (loads pages; asks above 50k rows). Context
menus: Copy Branch Name, Copy SHA, Pin to Left / Unpin, Solo, Show in Graph; tags: Copy Tag Name, Copy SHA,
Show in Graph, Show Tag Message (annotated). No checkout or mutation (Phase 4).

Tests: `NavigatorTreeBuilderTests` (grouping/collapse, natural sort current first, remotes/tags,
unborn/no remotes, filter expansion, `navigator10kBranchesBuildUnder50ms`), `NavigatorFilterTests`.
