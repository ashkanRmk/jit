# P2.5 — Lane layout

Algorithm, colours and golden format: [ADR-0021](../../../adr/0021-lane-layout.md).

## Tests
- Goldens (`LaneGoldenTests`): `lanesLinear`, `lanesSimpleMerge`, `lanesOctopus3`, `lanesCrisscross`,
  `lanesLongLivedDevelop`, `lanesRebasedBranch`, `lanes40Parallel`, `lanesDetachedHead`, `lanesOrphanRoot`,
  `lanesLateSecondParent10k` (first/last 8 rows; the lane stays open for 10k rows).
- Properties (`LanePropertyTests`): `lanesPrefixStableAnyPageSize` (seeded `GitTestKit.RandomTopology`, page
  sizes 1…2000 and pipe reads of 1…4096 bytes, failing seed in the message), `lanesDeterministicAcrossRuns`,
  `lanesColorStableForBranchName`, `headBranchUsesSlotZero`, `pinLeftAssignsLaneZero`.
- Performance: `lanesLayout100kUnder150ms` — 13 ms layout, 60 ms parse + layout + store (release).
