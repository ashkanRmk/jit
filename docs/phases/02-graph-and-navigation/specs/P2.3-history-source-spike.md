# P2.3 — Spike S1: history source

Question and candidates: design §4.3 / §7 (S1, S4). Harness: `JitBench history-source <repo>…` (release).
Numbers, decision and consequences: [ADR-0010](../../../adr/0010-history-loading.md).

Outcome: long-lived `git log --topo-order -z` with backpressure (`HistoryLoader`), readers killed on tab
deactivation (idle footprint 16–93 MB on ~100k-commit repositories), `--skip` restart with a drift
check. The `--skip` re-query and `rev-list` + metadata prototypes were deleted after measuring.

Correctness gate: `historyMatchesGitLogTopoOrder`, `historyMatchesGitLogOnSyntheticHistory` (row order
equals `git rev-list --topo-order --branches --remotes --tags HEAD`), `suspendedReaderResumesWithSkip`,
`driftAfterSuspendIsReported`.
