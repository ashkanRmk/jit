# P2.13 — Graph visual style: avatar nodes, elbow edges, ref column

Requested by the owner after the Phase 2 PR opened (2026-11-09): the graph follows the familiar
"avatar node" commit-graph convention instead of the original small-dot / S-curve look. This spec
replaces the geometry, node and ref-label parts of design §3.2; lane palette, rows, states and
performance budgets are unchanged.

## Behaviour

1. **Avatar nodes.** A regular commit's node is a circle of `nodeDiameter` (22 pt comfortable, 18 pt
   compact): a `nodeRing` (2 pt / 1.75 pt) in the lane colour around an initials avatar (author colour
   at 22 % / 32 % over the canvas, initials in the author colour). No network, no Gravatar (design §2).
2. **Merge nodes** are a small solid disc in the lane colour (`mergeDotDiameter` 10 pt / 8 pt), no avatar.
3. **HEAD** is marked by the ✓ current-branch label, not a ring around the node.
4. **Edges** keep their per-row segments (`EdgeSegment`, ADR-0021 unchanged) but lane changes are drawn
   as rounded elbows instead of S-curves:
   - `top` half from another lane into the node: straight down the source lane, a quarter turn of radius
     `r = min(mid, |dx|)`, then horizontal into the node at the row centre.
   - `bottom` half from the node out to another lane: horizontal from the node at the row centre, a
     quarter turn of radius `r`, then straight down to the row bottom.
   - `full` segments are straight (lanes passing by never change lane inside a row).
   - Every path stays inside its row rectangle, so a row is still drawable in isolation.
5. **Row band.** Each commit row gets a band in its lane's fill colour (14 % light / 22 % dark) from the
   node centre to the graph column's trailing edge, `nodeDiameter` tall, plus a 2 pt bar in the lane
   colour at the trailing edge. WIP and footer rows have no band.
6. **Ref column** ("Branch / Tag"), the first column, default 150 pt, resizable and persisted:
   - Shows the row's first label (current branch first, as today's ordering) as a pill, then `+N` if more.
   - Current branch: ✓ glyph + semibold. Local, remote, tag and detached-HEAD pill styles as design §3.2.
   - A 1 pt connector in the lane colour (60 %) runs from the pill's end through the graph column to the
     node's edge.
   - Right-click on a pill keeps the existing label menu; `+N` lists all refs in the menu.
7. **Author column** shows the name only (the avatar is now on the node).
8. **Density metrics** (DesignSystem `GraphMetrics`):

   | Token | Compact | Comfortable |
   |---|---|---|
   | rowHeight | 26 | 32 |
   | laneSpacing | 20 | 24 |
   | nodeDiameter | 18 | 22 |
   | nodeRing | 1.75 | 2 |
   | mergeDotDiameter | 8 | 10 |
   | edgeWidth | 1.75 | 2 |

## Performance

Avatars are rendered once per (initials, author colour, lane colour, diameter, scale, appearance) into a
`CGImage` cache on `GraphStyle` (cleared on appearance or density change) and blitted per draw — no text
layout per row. Row draw p95 must stay ≤ 1 ms (P2.6 budget); scroll p95 stays < 16.7 ms.

## Tests

- Elbow geometry: top/bottom elbows start/end on the expected lane centres, end horizontally at the row
  centre, and stay inside the row rect; `full` is a vertical line.
- Metrics: node fits the row; lane spacing ≥ node diameter; column width formula.
- Avatar cache: same key → same image instance; appearance change clears it.
- Ref column: first label + overflow count; the label menu still resolves the label under the click.
