# P2.9 — Search, scope, pin, solo, file history

- Scope menu: All / Current / Local / Selected… (checklist popover with filter), persisted per tab.
- Pin to Left / Unpin (navigator, label menus) seeds lanes 0…p−1 (`LaneLayouter` reservations).
- Solo (navigator, label and row menus) → scope `.solo`, chip `Solo: x ✕`.
- Search (⌘F, Edit ▸ Find): tokens text / `sha:` / bare hex / `author:` / `ref:`; loaded rows scanned in
  memory (`HistorySnapshot.search`), counter `n of N`, ↩ / ⇧↩ and ⌘G / ⇧⌘G, Highlight vs Show Only Matches
  (flat list, dots instead of lanes); "Search All History" streams `git log --grep/--author --fixed-strings
  --regexp-ignore-case` ids (stops at 5,000), cancellable; "Show First Match in Unloaded History" loads to it.
- File history from the inspector's file menu: `-- path` with `--follow` for files (chip tooltip "Rename
  tracking is heuristic"), without for folders. ⇧⌘H with a typed path is not built (see progress.md).
- Esc clears search, then solo/file history, then a compare selection.

Tests: `HistorySearchTests` (free text, hex prefix, author, ref token, fixed-string metacharacters,
`searchLoaded100kUnder30ms`, deep search finds bodies, `searchDeepCancel`), `historyFileHistoryFollowsRename`,
`pinLeftAssignsLaneZero`; solo/scope via `HistoryQuery.revisions` exercised by `historyReaderExitMapsError`.
