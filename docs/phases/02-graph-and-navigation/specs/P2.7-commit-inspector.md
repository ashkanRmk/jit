# P2.7 — Commit details inspector

Design §3.4. `RepositoryHandle.commitDetails(oid)` (`git show -s` with NUL-separated fields + `diff-tree
--no-commit-id -r -z -M --raw --numstat` against the first parent, `--root` for root commits), LRU of 32;
`InspectorModel` cancels the previous request on reselection. View: subject, reflowed body (hard-wrapped
paragraphs joined; lists, indented lines and trailers kept), meta grid (author, committer if different, dates,
SHA with copy, parent links that select/load the parent, refs), changed files (status letter, dimmed
directory, `old → new` for renames, ± numbers and 8-segment bar, flat/tree), "First parent | Combined"
(Combined disabled: "Combined diff is planned"). File rows: Show File History / Folder History, Copy Path —
no diff action (Phase 3). Spinner after 120 ms.

Tests: `detailsRootCommit`, `detailsMergeFirstParent`, `detailsRenameDetected`, `detailsBinaryNumstatDash`,
`detailsUnicodePaths`, `detailsCachedAndCancelledOnReselect`, `MessageReflowTests`.
