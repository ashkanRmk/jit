# P2.6 — Graph renderer

Design §3.2, §4.5; decision and measurements: ADR-0009.

## Behavior
- `GraphViewController` hosts a view-based `NSTableView` (graph, subject+pills, author, date, SHA). The SHA
  column hides first and the author column narrows when the pane is narrow; the subject column absorbs width.
  Column widths persist per tab (`ui["graph.columns"]`). The graph column fits the lanes of the rows on screen.
- Rows: WIP row on top when the working tree is dirty and HEAD is in scope (not in solo / file history /
  only-matches); end-of-history footer ("Beginning of history · N commits" or the shallow note).
- States: static 12-row skeleton until the first page, "No commits yet", error banner with Retry, toolbar
  spinner after 150 ms.
- Prefetch: bounds-change → `HistoryController.visibleRowsChanged` (500 rows before the end, 2,000 per page).
- Hover fades (100/140 ms, none during live scroll or with Reduce Motion); selection uses the system accent.
- Glass only in the floating bar (`GlassControlGroup`); table opaque.

## Tests
`LaneGeometryTests` (lane x, compression, pixel snapping at 1×/2×), `RefLabelTests`, `DisplayTextTests`;
app tests (23) still pass. Snapshot tests were replaced by real window captures in `screenshots/` (no
