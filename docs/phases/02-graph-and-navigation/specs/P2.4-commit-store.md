# P2.4 — Commit store & history reader

## Behavior
- `HistoryLoader` (actor) per history view: `ensureLoaded(minRows)` → `HistorySnapshot`; one read in flight,
  shared by concurrent callers; `close()` kills the reader; `suspendReader()` (tab hidden) kills it but keeps
  rows; `resetFailure()` for Retry. Signpost interval `HistoryPage` (subsystem `jit.performance`).
- `HistoryQuery`: scope (`all` = `--branches --remotes --tags HEAD`, `current`, `local`, `refs`, `solo`), path
  (after `--`), `follow` (single path), pinned refs. Unborn HEAD is never passed; a scope with nothing to read
  is an empty, complete history. Revisions follow `--end-of-options`.
- `LogParser`: incremental byte parser of `%H %P %aN %aE %at %s` NUL-separated records (`memchr`), reused
  record buffer, no `String` per field.
- `CommitStore` / `HistorySnapshot` / `CommitRow`: ADR-0022.

## Failure cases
Reader exits non-zero → mapped `processFailed` (e.g. bad revision) — loaded rows stay; output ends inside a
record → `internalError`; resume drift → "The history changed while it was loading".
