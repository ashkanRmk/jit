# P2.10 — Compare

Two commits selected (⌘-click / ⇧-click; a third replaces the oldest) → inspector "Comparing a → b" ordered
older → newer, swap button, "Changes on B since common ancestor" (`a...b`, default) vs "Direct difference"
(`diff-tree a b`). WIP + a commit (or row menu "Compare with Working Directory") → tracked changes vs the
working tree with the note "Tracked files only — untracked files are not included". Row menu "Compare with
Selected" when another commit is selected.

Tests: `compareTwoDotVsThreeDot` (checked against `git diff --name-status`), `compareWithWorktreeExcludesUntracked`,
`compareRenames`.
