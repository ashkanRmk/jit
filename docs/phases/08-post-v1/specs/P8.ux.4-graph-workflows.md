# Graph workflow fixes

Requested 2026-11-17. Screenshot text is a visual/product reference.

1. Fix keyboard focus in changed files, hand cursors, full-row column resizing and stale row drawing. Bound ref pill layout so long names and many refs cannot overlap; distinguish HEAD.
2. Remove inspector resize animation. Reveal HEAD on first history load and after completed Git actions, including commits and checkout.
3. Put operation progress in the matching repository action icon, disable other actions and tab switching. Show dismissible success/error toasts at the window bottom left, respecting Reduce Motion.
4. Add lightweight/annotated tag creation, optional immediate push with remembered preference, selected-ref shortcuts (Cmd-T, Cmd-Shift-T, Cmd-P, Cmd-Shift-P), double-click checkout, and expanded branch context actions.
5. Verify with real temporary Git repositories, feature tests, app build and visual captures. Cloud Patch is a provider service from the reference app and is outside Jit's integrations; provide local patch export.

Keyboard: Cmd-T creates a tag at the selected graph commit; Cmd-Shift-T copies the selected tag. Cmd-P pushes and Cmd-Shift-P pulls the selected branch (falling back to the current branch when there is no ref selection). New Tab is Option-Cmd-N; Reopen Closed Tab is Option-Cmd-Shift-T.

Implementation includes leased remote deletion with optional local deletion, reset soft/mixed/hard with explicit confirmation, detached worktree creation, patch export, upstream management, branch merge/rebase/fast-forward and pin/solo. The ref menu uses the exact pill clicked, including labels expanded on hover, and avoids repeating commit actions.

## Hover overlap follow-up

The initial pill-width regression checks did not cover native table compositing. The expanded hover strip was a child of NSTableView, whose recycled/layer-backed row views could render above it. The strip now lives in the scroll clip view above the whole table, uses converted table coordinates for hit testing and scrolling, and applies its final width without a cached-layer resize animation. Mouse and menu events still go to the table.

Added a regression that inserts another table child after the overlay is shown and verifies overlay stacking/scroll coordinates. Added and visually reviewed light/dark full-graph hover snapshots with two long remote branch names and multiple tags. All 178 feature tests and lint pass; the debug app builds. Native composited-window checks confirmed separated expanded labels and the correct context menu for the second branch.


Reinstallation exposed an independent startup stall: the installed process was blocked on the main thread inside FSEventStreamCreate while opening watched parent directories. Watcher registration now runs off the UI executor, reconciles status after startup, and cleans up a delayed stream if the tab is deactivated first. A semaphore-controlled real-stream regression verifies status loads while registration waits and no stream survives deactivation. The 15 session/history and 13 graph/lifecycle tests pass, along with lint and the app build. The installed app was reopened and its populated, responsive window verified.
