# Reflog explorer

Status: implemented locally, 2026-11-18.

Repository ▸ Reflog and the command palette open an opaque, keyboard navigable workbench list with
HEAD/local-branch picker, action, message, event time, SHA and unreachable status. Loading is delayed;
empty and error states explain reflog expiration/disabled logging and offer refresh or lost-commit scan.
The scan runs only on request, with progress/cancel and a clear bounded-results notice.

Selection inspects the commit without changing the repository. Show in Graph temporarily includes the
selected lost tip, marked with dashed graph edges, without persisting a ref or changing saved filters.
Actions reuse Create Branch, Cherry-pick, Compare, Copy SHA and confirmed Reset. Recovery of Jit-recorded
operations names the exact previous state; no blind HEAD@{1} reset. Closing, hiding or tearing down the
tab cancels read work. Mutations are disabled while the repository is busy.

Verify amend → inspect old commit → create recovery branch, with unchanged index/worktree; snapshots
in light/dark, native UI checks, keyboard navigation, build, lint and relevant integration suites.
