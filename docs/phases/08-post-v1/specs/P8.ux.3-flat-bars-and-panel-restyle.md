# P8.ux.3 — Flat bars and panel restyle (0.0.4)

> Status: **implemented** (2026-11-11). The third owner-requested UX round, on top of
> [P8.ux.2](P8.ux.2-action-bar-sidebar-and-diff.md). The owner supplied reference screenshots for the
> uncommitted-work panel, the commit panel and the diff header; this round follows their structure with Jit's
> own tokens. Choices the request left open are marked *(decision)*.

## 1. Tabs disappearing from the toolbar (bug)
- Symptom: after switching tabs (or resizing), the toolbar showed only the sidebar toggle and a `»` overflow
  button; the tab strip was inside the overflow.
- Cause: the strip's width assumed the sidebar toggle stays beside the window controls. When the tracking
  separator was not in effect, the system laid the items out after the sidebar, the strip no longer fit and
  was moved to the overflow.
- Fix: no tracking separator. The system places the toggle and the strip after an open sidebar; the strip's
  width is the window width minus the sidebar (or the window controls when it is closed), the toggle and the
  activity item, and uses the strip's measured position when it is on screen.

## 2. Action bar
- No glass and no container: a centred row of plain tools with their names — Pull, Push, Fetch, Branch,
  Stash, Pop, Terminal, then the changes count and Search — on an opaque strip of the canvas.
- A step smaller (14 pt symbols, tighter padding).
- Progress, chips (solo, file history) and the open search field keep the trailing end.

## 3. Diff header
- A flat, opaque two-row header instead of floating glass capsules.
  - Row 1: the file path (folders dimmed, name whole), **Stage File** / **Unstage File** for working-directory
    diffs, Close.
  - Row 2: which side is shown (left), **File View | Diff View** (middle), tools on the right — Blame,
    previous / next change with the count, unified / side by side, ignore whitespace, wrap, find, options.
- Narrow panes fall back to navigation, find and one menu.
- The code text size is unchanged (12 pt at the default step); a saved larger step is the user's setting
  (View ▸ Smaller Code Text, ⌘−).

## 4. Uncommitted-work panel
- Header: Discard All (outlined red trash) on the left, "N file changes on `<branch>`" centred; below it sort,
  a labelled **Path | Tree** switch and the filter field. *(decision: the filter stays.)*
- Sections read "Unstaged Files (n)" / "Staged Files (n)" with outlined **Stage All Changes** (green) and
  **Unstage All Changes** (red).
- Rows: a change glyph (plus, pencil, minus, arrow, warning) instead of a letter and a file-type icon; the
  hovered or selected row shows an outlined **Stage File** / **Unstage File**.

## 5. Commit panel
- `commit: <short sha>` with a copy button, the message in a sunken box (subject, body scrolling at a fixed
  height), then the author — picture, name, "authored <date>" — with the parent(s) on the right, and the refs
  on the commit.
- Files: a summary per kind ("4 modified", "1 added") with the line totals, a labelled **Path | Tree** switch,
  rows with the same change glyphs.

## 6. Sidebar
- The logotype sits at the top right of the sidebar, in the toolbar's height.
- A section's count keeps clear of the system's show / hide chevron.

## 7. Panel widths
- The sidebar and right-panel widths were already shared by all tabs, but a new repository tab could open at
  the default widths when its first layout ran before the split view had its size. They are now applied
  again when the tab's view appears and when the sidebar reopens.

## 8. Graph
- The branch-of-a-line label is dimmer (40 % hovered, 55 % selected), so it does not read as a real label.
