# Reset preview sheet

Status: included in 0.0.8, 2026-11-18.

Graph and Reflog menus offer Soft, Mixed, Keep and Hard with plain-language descriptions. Each opens a
loading/error/ready preview sheet. The existing ConfirmationSheet remains the only token-minting action;
Cancel is default, and hard reset keeps its high-risk arming delay. The sheet names repository, branch,
target, old HEAD, local files and lost commit reachability (first five subjects plus total).

Dirty hard resets default to Stash changes first (including untracked files). Identity is required only
when a stash will be created. The destructive button names reset versus stash-and-reset; the preview shows the affected
file count. Obstructions disable confirmation and explain how to refresh safely. No mutation runs while
preparing a preview or changing a checkbox. Busy repositories cannot start another reset.

Success displays recovery information from the outcome/journal. Failed chains explicitly retain and name
the saved stash. Verify real hard-reset/stash/reflog recovery, keyboard/Cancel behavior, and light/dark/
opaque snapshots. The implementation is merged for 0.0.8.
