# P8.ux.1 — Graph, panels and tab polish (0.0.2)

> Status: **implemented** (2026-11-10, branch `feat/graph-ux-0.0.2`). An owner-requested UX round outside the
> Phase 8 epics. Decisions the owner made when asked: pictures from **Gravatar** (ADR-0050); a file's diff
> **replaces the graph** in the centre pane; the release is **pushed and published**.

## 1. Ref labels (graph "Branch / Tag" column)
- Where a branch lives is shown by glyphs, not text: `laptopcomputer` = local, `cloud` = remote, both when a
  local branch and its upstream are on the same commit (was `main ⇄ origin`). A remote-only branch shows the
  cloud and the branch name without the remote prefix (was `origin/x` with a dimmed prefix).
- **Hover** over the column: every label of the row is shown in full (the cell shows one pill and `+N`),
  in `RefsHoverView`, an opaque strip over the row that grows from the cell's width to the width it needs
  (`motion.select`, ease-out; instant with Reduce Motion; never past the table's visible edge) and fades out
  (`motion.feedback.out`). It hides on scroll, reload, selection change and column changes.
- **Tooltips** (owned by the hover view, per region): computer → `Local branch <name>`; cloud → the full
  remote name (`origin/main`); name → a one-line summary (`main — local and origin/main`, `Tag v1`, …).
- Context menus work on the pill under the pointer in the expanded strip; clicks, double-clicks and scrolling
  go to the table.

## 2. Author on the graph node
- The node shows the author's picture when Gravatar has one (inside the lane ring), initials otherwise.
- Resting the pointer on a node (avatar or merge dot) shows `name / email / date`.

## 3. Columns
- A header shows the column names. Drag a header to **reorder**; drag an edge to **resize**; right-click the
  header to **show or hide** columns and to reset. The message column cannot be hidden; the graph column
  sizes itself to the lanes on screen and cannot be resized.
- The message column takes the width the others leave, so dragging its edge resizes its neighbour.
- Narrow panes: the SHA hides, then author, date and branch narrow to their minimum (`GraphColumnLayout.fitted`).
  These are layout results and are not saved.
- Order, hidden columns and preferred widths are saved with the tab (`ui["graph.columns"]`; the pre-0.0.2
  width-only value is still read) and seed new tabs (`PreferencesStore.graphColumns`).
- The connector between the branch column and the node is drawn only when the graph column follows it.

## 4. Diff in the centre pane
- Choosing a changed file (commit, comparison or working directory) shows its diff over the graph area
  (200 ms fade, instant with Reduce Motion). The inspector keeps the commit and the file list; choosing
  another file swaps the diff without animation.
- Esc, the diff's close button or View ▸ Close Diff (⌥⌘↩, was "Focus Diff") return to the graph and clear
  the file's highlight. Selecting another commit closes it as before.
- Removed: the diff pane under the file list, and "Focused Diff" as a separate mode.

## 5. Side panels
- **Inspector:** one container per section (`panelSection()` = `contentCard`): message; people (picture,
  name, role, email, date); SHA / parents / refs; files. Comparison headers and their file lists likewise.
- **Working directory:** each of Conflicts / Staged / Unstaged is one container: header row, file rows, gap.
- **Sidebar:** a rounded container behind each top-level section (Local, Remote, Tags, Stashes) and its rows,
  drawn in the outline view's background.
- **File paths never cut the file name.** Inspector rows: `folders/` + `name`; the folders shorten in their
  middle and disappear below 36 pt (`FilePathLayout`). Working-directory rows: name first, folder after it,
  the folder gives way first.

## 6. Command bar, inspector, tabs
- The commit search is a magnifier button that opens into the field on click or ⌘F and folds back when it is
  empty and loses focus (or on Esc). The find group sits at the trailing end of the bar.
- Selecting a commit slides the inspector in (system split-view animation, `motion.panel`; instant with
  Reduce Motion), then settles on the shared width.
- Closing a tab no longer animates the strip: the closed tab disappears and the others take their places at
  once (its glass used to slide behind a neighbour first).

## 8. Not verified by automation
Pointer-driven behaviour — header drag-reorder and drag-resize, the hover strip following the pointer, the
tab-close and inspector animations in motion — was exercised only through code paths and debug launch
arguments (`-JitGraphHoverRow`, `-JitInspectorOpenFile`), not with a real pointer.
