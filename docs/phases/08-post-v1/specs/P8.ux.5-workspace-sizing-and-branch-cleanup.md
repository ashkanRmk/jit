# Workspace sizing and branch cleanup

Requested 2026-11-18. Local implementation; no release or publication implied.

## Plan and acceptance

1. Preserve exact user-selected graph column widths during drag, subsequent fitting, refresh and restore.
   Automatic columns may narrow; long names truncate. Horizontal scrolling handles a large chosen width.
2. Explain the remote list as Git's cached remote-tracking refs. Fetch with prune by default; expose a
   per-remote refresh button and make Fetch All actually fetch every remote.
3. Offer individual local-only branch trash actions and bulk cleanup from Local/Remote headers and
   their context menus. Reuse the explicit ConfirmationRequest/ConfirmationToken flow. Refresh all remotes
   first, check live remote heads, and show the full, scrollable list before confirming bulk removal.
   Preserve current/worktree branches and unmerged branches. Stop if a remote cannot be checked, a branch
   was published during confirmation, or the repository snapshot changed. Individual deletion retains its
   existing unmerged-commit review and second confirmation.
4. Add persisted 75–150% workspace zoom with ⌘+, ⌘=, ⌘− and ⌘0. Scale AppKit and SwiftUI content through
   one workspace scale; fonts, icons, row heights, spacing and hit testing use the same scale.
   SwiftUI hosts counter the AppKit canvas transform and apply their own SwiftUI scale so gesture targets
   follow the rendered controls. Flexible headers do not impose their previous width on the split view.
   Keep system window chrome native. Preserve a usable minimum canvas and scroll at small viewport sizes.
5. Validate against real temporary repositories and bare remotes, exercise drag and confirmation actions,
   render light/dark layouts at 960/1180/1600 points and 75/100/150%, then update README and verification notes.

## Regression coverage

- Exact arbitrary branch column widths round-trip and survive narrow layout fitting and mouse dragging.
- Deleted remote refs disappear after prune; renamed upstreams, multiple remotes and narrow fetch refspecs
  do not make a live branch eligible for deletion.
- Wrong confirmation, stale state, newly published branches, inaccessible remotes and no remotes refuse
  cleanup without deleting branches. Checked-out and unmerged branches stay intact.
- Real mouse events hit the intended SwiftUI button at 75%, 100% and 150%.
- Zoom shortcuts, persistence, physical drawing scale, visible sidebar and split-pane separation across size/appearance
  combinations. Evidence PNGs can be exported with `JIT_UI_EVIDENCE_DIR` in WorkspaceInteractionTests.
