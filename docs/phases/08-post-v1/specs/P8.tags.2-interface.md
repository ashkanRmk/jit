# Tag management interface

Status: implemented locally/unreleased, 2026-11-18. [Verification](../progress-tags.md).

- Reuse the create sheet with an Annotated toggle, multi-line message, active identity guidance and
  persisted push-after-create choice. Return inserts a newline; Cmd-Return submits once.
  Disable invalid/empty annotation or missing identity submissions.
  Create at a selected older commit or HEAD from sidebar add/context menus and command palette.
- Distinguish annotated/lightweight sidebar icons and accessibility descriptions. On-demand tag details
  popover shows type, tagger/date/message, direct/peeled IDs, copy actions and explicit remote selection
  for push/delete. Actions remain available for non-commit tags; graph-only actions stay absent.
- Share management actions between sidebar, graph label menus and palette. Local/remote deletion uses
  ConfirmationSheet, exact recovery OID and default Cancel; remote deletion has the existing arming delay.
  Loading/error/retry states never imply success. Busy repositories cannot start another mutation.
- Create-and-push failure explicitly preserves the local tag. Push failures remain failures even when
  Git emits a porcelain rejection with exit status 0. Closing a popover cancels its read work.
- Verify create an annotation on an older commit, push it to a bare remote, delete remotely with the
  local tag intact, then delete locally with recovery metadata. Capture light/dark/opaque snapshots,
  native-window checks and read-only timings. Commit locally; no merge or release in this task.
