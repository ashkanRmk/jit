# P8.rebase-interactive — Plan, editor and execution

## Behavior
- Graph “Interactive Rebase from Here…” includes the selected commit through HEAD. Branch menu and
  command palette open a base/onto chooser. Plans contain at most 500 linear commits, oldest first;
  merge-containing ranges, a non-ancestor base, detached/unborn HEAD and root-inclusive ranges are refused.
- Pick, Reword, Edit, Squash, Fixup and Drop; drag or Option-Command-Up/Down reorders the selected row.
  Reword and squash messages are editable, with a resulting-history preview and published-history warning.
- Run opens the existing specific confirmation sheet. The token binds the plan ID and exact edited steps.
  The writer revalidates the plan, refs, clean tracked tree, active operation, and range before touching Git.
- Native `rebase -i --force-rebase --no-autostash --no-autosquash --no-update-refs --keep-empty
  --empty=ask --no-rebase-merges --no-fork-point` drives the existing conflict and operation UI.
  Initially empty commits are kept; newly empty commits stop for an explicit decision. Other branch refs
  never move implicitly. Authors are preserved, and the captured profile supplies committer identity.
- The bundled helper supplies a generated todo and messages through private files (0700 directory,
  0600 files), with no user text in shell commands. Messages are keyed by original commit IDs from Git's
  completed todo rather than an editor-call counter, so conflicts and skip cannot shift later messages.
- Prepared messages and captured identity survive app relaunch. Continue/Skip require the trusted helper
  for Jit-managed rebases; abort remains available without it. Data is removed after completion/abort.
- Edit stops route to Working Directory with “amend, then Continue”; progress follows Git's stderr events
  and sequencer files, without timers. Recovery uses the existing journal and Git reflog.

## Validation
Real repositories: reorder/reword, squash/fixup chains, drop/all-drop, edit/amend/continue, conflict
resolve/continue and abort, restart/skip, identity/authors, stale plans, malformed/duplicate/injected
steps, leading squash/fixup, empty messages, merged/root ranges, dirty trees, unrelated files and refs,
private file modes, helper paths with shell metacharacters. Feature workflow tests and light/dark captures.
