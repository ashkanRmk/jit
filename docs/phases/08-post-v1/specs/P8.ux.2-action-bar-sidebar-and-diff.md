# P8.ux.2 — Action bar, sidebar, diff and panel round (0.0.3)

> Status: **implemented** (2026-11-10, branch `feat/0.0.3-ux`). The second owner-requested UX round outside the
> Phase 8 epics, on top of [P8.ux.1](P8.ux.1-graph-and-panels.md). Where the request left a choice open, the
> choice made is marked *(decision)*.

## 1. Window toolbar
- The toolbar holds the sidebar toggle and the tab strip only. Removed: the profile item (now in the sidebar),
  the inspector toggle (View ▸ Show Inspector, ⌥⌘0, stays) and the "All Tabs" chevron menu (the Window menu
  lists every tab).
- The sidebar toggle is the system item drawn as the icon alone (`isBordered = false`); it stays beside the
  window controls, with the tracking separator after it.
- The strip's width is always derived from the window width, the sidebar edge and the activity item, and is
  recomputed on resize, zoom and full-screen changes, so no item changes place or drops out.
- Tabs are rounded rectangles (`TabMetrics.shape`, `radius.md`), not capsules.

## 2. Action bar (under the tabs)
- One glass bar (`ChromeShape.control`) over the top of the graph: **Pull, Push, Fetch, Branch, Stash, Pop,
  Terminal** as plain icon-over-title items (`BarAction`): no border, no glass of their own, a hover wash.
  Pull shows `↓n`, Push shows `↑n` or reads "Publish".
- A click runs the main action (Pull = fast-forward only; Fetch = the default remote). The other variants are
  in the item's context menu and in the Repository menu. *(decision)*
- Trailing side: transient chips (solo, file history), the changes count (selects the working directory) and
  Search, which opens into the field.
- Narrow panes: titles drop first (also View ▸ Command Bar ▸ Show Labels), then Terminal, Stash/Pop and
  Branch move into `⋯` (`CommandBarLayout`, unchanged rules).
- Removed from the bar: the repository › branch breadcrumb (the branch moved to the sidebar) and the
  "which branches the graph shows" menu. The graph always shows all branches; a saved scope is ignored.
  Solo and pin (sidebar context menu) remain.

## 3. Left sidebar
- **Top:** the current branch (name, `↑n ↓n`), a button that lists every branch with a filter; choosing one
  switches to it.
- **Bottom:** the active Git profile (opens the profile switcher popover from there) and the Settings button.
  With no profile it reads "No Profile" in `status.warning`. The same row is at the bottom-left of the
  new-tab page. With the sidebar closed, the switcher opens from the same corner of the content.
- Section titles carry a glyph: computer (Local), cloud (Remote), tag (Tags), tray (Stashes).
- Rows are 26 pt with text one point larger than the system size.
- The section containers are a light wash (`state.hover` at 45 %) so the sidebar's glass shows through.

## 4. Diff viewer
- Opening a file's diff closes the left sidebar; closing the diff (Esc, its close button) brings the sidebar
  back. The tab's saved sidebar state is not changed. Toggling the sidebar by hand while a diff is open ends
  the automatic behaviour.
- Esc with a diff open closes the diff only: the selection and the right panel stay, wherever the keyboard
  focus is (it used to clear the selection when the focus was still in the graph).
- **Word wrap** (off by default, remembered): long lines wrap inside the pane, in unified, side-by-side and
  full-file layouts; no horizontal scrolling while it is on.
- The bar has direct buttons, with on/off state: unified, side by side, full file, ignore whitespace changes,
  word wrap. Icons are one step larger.
- **Stage File** (green) on an unstaged file's diff, **Unstage File** (red) on a staged one; the diff then
  shows the file on its new side.

## 5. Right panel — uncommitted work
- Order: Conflicts, **Unstaged**, then **Staged**.
- File rows show the full path like the committed list (folders shorten in the middle, the name is never
  cut). The Stage / Unstage button always fits: it takes the place of the line counts on hover or selection.
- Stage and Stage All are green, Unstage and Unstage All are red.
- **Discard All** (red trash) in the Unstaged header: every unstaged change goes through the same
  confirmation sheet as a single discard.
- Commit box: no "Committing as …" line when a profile is active; larger summary and description fields in
  their own containers; `n/72` for the summary and a character count for the description; a non-blocking
  warning for a summary or description lines over 72 characters; a full-width Commit button; ⌘↩ commits from
  either field.

## 6. Right panel — a commit
- The panel does not scroll as a whole. The message keeps a fixed height (a long body scrolls inside it) and
  the files container takes the rest and scrolls inside itself.
- File rows are one step larger.
- The Tree toggle shows a real tree: folders closed by default with a plus (minus when open), single-child
  folder chains merged, files indented under their folder.
- The panel's default width is 420 pt (was 360); a saved width still at the old default follows it.

## 7. Graph
- **Branch of a line:** hovering a commit without labels of its own shows, dimmed, the label of the branch
  line it sits on; a selected commit keeps it.
- **Time tags:** instead of a date on every row, a small tag at the trailing end where the time changes
  ("7 hours ago", "yesterday", "3 days ago", …) with a hairline across the row. The Date column is hidden by
  default and can be shown again from the header menu.
- The graph column keeps its width while scrolling: the width the user dragged, or one automatic width from
  the loaded history. It no longer follows the rows on screen.
- The expanded label strip is always opaque (it could stay half-transparent, with the row's own labels
  showing through).

## 8. Shapes and identity
- Radii are one step squarer: `xs` 3, `sm` 5, `md` 7, `lg` 10 (were 4 / 6 / 10 / 14). Jit's own glass controls
  use `ChromeShape.control` instead of capsules.
- A logotype (`JitLogotype`): "jit" in one rounded line weight, the dots of the j and the i as two commits on
  a lane that runs into the t. Shown on the new-tab page.

## Not in this round
- A setting to bring back the branch scope menu or a per-row date; both can be revisited if missed.
