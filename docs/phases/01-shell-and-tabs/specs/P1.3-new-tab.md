# P1.3 — New-tab page and opening repositories

## Behavior
- Opaque `surface.canvas` page, centered 640 pt column: quiet "Jit" wordmark, the single primary glass
  action "Open Repository…" (⌘O, `primaryGlassButton`), one-line hint, "Recent" list (up to 12) in an
  opaque card: name, last branch, middle-truncated path, relative last-opened time (formatted once per
  render — no live-updating date). Hover reveals Reveal in Finder / Remove from Recents.
- Missing recents: `text.disabled` row "Not found — <path>" with Locate… / Remove.
- Keyboard: arrows move, Return (or double-click) opens, ⌫ removes, ⌘Z restores at the same position.
- Empty recents: one sentence, no illustration. No Clone or provider entries (Phases 4/5).
- Window-wide drop: dragging a folder anywhere over the content shows an opaque overlay (canvas at 92 %,
  dashed `accent.base` outline, "Open as Repository"); dropping opens it. Non-folders are refused.
- Open flow: `GitEngine.openRepository` (discovery once) → resolved top level → an existing tab with the
  same path is focused; otherwise the active new-tab page is replaced, or a tab is added after the
  active one. Failures show a sheet alert with the summary and guidance. Recents updated.
- File ▸ Open Recent lists recents (missing ones disabled) with Clear Menu. Folders opened from Finder /
  `open -a Jit <folder>` open as tabs.
- Launch hooks: `-JitOpen <path>` / env `JIT_OPEN` (all builds); `-JitUITestOpenRepository <path>` (debug).
