# P1.9 — Menus, shortcuts, theme, restore

## Menus (built in code, `MainMenu`)
| Menu | Items |
|---|---|
| Jit | About, Settings… ⌘,, Services, Hide ⌘H, Hide Others ⌥⌘H, Show All, Quit ⌘Q |
| File | New Tab ⌘T, Open Repository… ⌘O, Open Recent ▸ (+ Clear Menu), Close Tab ⌘W, Reopen Closed Tab ⇧⌘T, Close Window ⇧⌘W |
| Edit | Undo ⌘Z, Redo ⇧⌘Z, Cut, Copy, Paste, Delete, Select All |
| View | Show/Hide Sidebar ⌃⌘S, Show/Hide Inspector ⌥⌘0, Appearance ▸ System/Light/Dark, Enter Full Screen ⌃⌘F |
| Repository | Refresh ⌘R, Reveal in Finder ⌥⌘R, Open in Terminal ⌥⌘T, Copy Repository Path ⌥⌘C |
| Window | Minimize ⌘M, Zoom, Show Next/Previous Tab ⌃Tab / ⌃⇧Tab (+ hidden ⇧⌘] / ⇧⌘[), Move Tab Left/Right, Bring All to Front, tab list |
| Help | Jit Help ⌘? (opens the README in the browser; Jit makes no request itself) |

No Branch or Git menus. Repository items are disabled on a new-tab page; Reopen is disabled with an empty
stack; tab cycling needs two tabs. ⌘W in Settings closes that window. Repository actions go through
`NSWorkspace` (Terminal via `open(_:withApplicationAt:configuration:)`), never a shell.

## Theme (P1.7)
`PreferencesStore.appearance` (System/Light/Dark) from Settings ▸ General or View ▸ Appearance, applied
to `NSApp.appearance` in `applicationWillFinishLaunching` (before any window — no flash) and live on change.

## Restore (P1.10)
`session.json` is read synchronously before the window exists; tabs appear with cached titles and hollow
dots; only the active tab's session activates, one main-queue turn after the window is shown. Missing
repositories become error tabs without blocking others. "Restore tabs on launch" off → a new-tab page.
