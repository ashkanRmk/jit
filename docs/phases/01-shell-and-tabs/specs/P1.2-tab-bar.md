# P1.2 — Tab bar

## Spike result (2026-11-09) — placement and glass container
- **Toolbar item, not titlebar accessory.** A custom-view `NSToolbarItem` in the unified toolbar keeps
  traffic-light spacing, full-screen toolbar reveal and system item grouping without private API.
- **The toolbar wraps custom-view items in its own glass platter** (macOS 26/27, verified by real screen
  capture). Glass tabs inside it would be glass nested in glass. `NSToolbarItem.isBordered = false`
  removes the platter (verified), so the strip item is unbordered and the strip itself is the single glass
  surface. AppKit has no `sharedBackgroundVisibility` equivalent; `isBordered` is the documented switch.
- **Hosted SwiftUI `GlassEffectContainer`, not `NSGlassEffectContainerView`.** SwiftUI gives
  `glassEffectID` morphs between tabs (AppKit glass views have no morph identity), hover/interactive
  glass, and is far less code. Idle cost is measured in P1.10 (glass is static when idle: no animations,
  no timers). A full AppKit implementation was not built; the deciding factor was morph support.
- With an expanded sidebar the toolbar's leading items start at the sidebar's trailing edge; the strip
  width is computed from that edge, the measured profile capsule and the fixed system items, and is
  recomputed on window resize, tab switch, sidebar collapse/resize and profile change (event-driven).

## Behavior
- Toolbar: `[sidebar toggle] [tab strip … (+)] [⌄ all tabs] [inspector toggle] [profile capsule]`. The
  window title is hidden visually (the strip shows the name); `title`/`subtitle` are set to the repository
  name and `branch ↑a ↓b` for Mission Control, the Window menu and VoiceOver.
- Tabs: equal width between 132 and 232 pt; status dot (none/hollow/accent/warning/danger), name, close
  button (hover or active). Select on mouse-down; drag past 4 pt reorders with neighbors sliding
  (`motion.select`), no animation after drop. Middle-click closes (an `NSView` overlay that accepts only
  other-mouse events). Tooltip: path + branch. Empty strip space drags the window; double-click follows
  the system "double-click title bar" setting.
- Overflow: below 132 pt per tab the row scrolls horizontally (glass container inside the scroll content
  so glass clips with it), the active tab scrolls into view; `⌄` lists all tabs with status and path.
- Keyboard: ⌃Tab / ⌃⇧Tab and ⌘⇧] / ⌘⇧[ cycle (wrap), ⌘T, ⌘W, ⌘⇧T; Window ▸ Move Tab Left/Right.
  ⌘1–⌘3 unbound (reserved).
- Accessibility: strip is a labelled container; each tab "<name>, <status>, tab n of m", selected trait,
  actions Close Tab / Move Left / Move Right; close buttons "Close <name>".
- Reduce Transparency: opaque `surface.chromeOpaque` capsules with `border.strong` hairlines; selected
  tab `accent.muted` + system accent edge. Increase Contrast: selected capsule gets an accent edge.
  Reduce Motion: no morph; a short linear cross-fade; reorder reflows instantly.
