# P1.4 — Workbench layout skeleton

## Behavior
- One `NSSplitViewController` per loaded repository tab: `NSSplitViewItem(sidebarWithViewController:)`
  (system glass sidebar, system `List` sidebar style), main item (opaque `surface.canvas`), and
  `NSSplitViewItem(inspectorWithViewController:)` (opaque `surface.panel`). Min/max from `PanelMetrics`.
- Widths are global (`LayoutState`), applied when a tab is shown and stored only on user divider drags;
  collapse flags are per tab (KVO on `isCollapsed`). ⌃⌘S / ⌥⌘0 and the toolbar toggles use the system
  collapse animation; instant with Reduce Motion.
- Repository header: name (`type.display`), branch / "Detached at <sha7>" / "<branch> — No commits yet",
  upstream with ↑ahead ↓behind (monospaced digits; "upstream gone" when the upstream branch is missing),
  operation chip (Merging, Rebasing n/m, Cherry-picking, Reverting, Bisecting, Applying patches).
- Main: staged / unstaged / untracked / conflicted cards; "No local changes." when clean. Sidebar:
  repository summary (name, path, kind, main repository for linked worktrees) — no Branches header.
  Inspector: working-directory counts, Open in Finder / Open in Terminal.
- States: loading (static placeholder only after 150 ms, no shimmer), normal, error (missing / not a
  repository / permission / Git missing…) with Retry, Locate…, Remove Tab, bare ("Bare repository — no
  working tree", no counts).
