# P0.4 — Build pipeline and project generation

## Behavior
- `scripts/build/build-all.sh [debug|release] [--test]` from a clean checkout: checks full Xcode ≥ 26 is
  selected and XcodeGen is installed (clear message and fix otherwise), generates `macos/Jit.xcodeproj`
  from `macos/project.yml`, builds `Jit.app`, and with `--test` runs `test-core.sh` and `test-app.sh`.
- Individual scripts: `gen-xcodeproj.sh`, `build-app.sh`, `test-core.sh` (`swift test`), `test-app.sh`
  (`xcodebuild test`), `lint.sh` (swift format + architecture greps). All `set -euo pipefail`, `--help`.
- DerivedData lives in `~/Library/Developer/Xcode/DerivedData/Jit` (override: `JIT_DERIVED_DATA`) —
  the xctest runner hangs when loading test bundles from a TCC-protected checkout such as `~/Documents`.
- App target `Jit`: macOS 26.0, arm64, Swift 6 + complete strict concurrency, Hardened Runtime forced
  on for ad-hoc signing (`OTHER_CODE_SIGN_FLAGS = --options=runtime`), App Sandbox off, bundle ID
  placeholder `com.example.jit`, `ENABLE_DEBUG_DYLIB = NO` in Debug (the preview dylib fails library
  validation under Hardened Runtime with ad-hoc signing).
- CI: `.github/workflows/ci.yml` on a macOS runner with Xcode 26+ selected explicitly.

## Failure cases
CLT-only `xcode-select`; Xcode older than 26; XcodeGen missing; unknown script argument.

## Tests
`JitAppTests` (`xcodebuild test`): `discoverTempRepositoryThroughEngine`, `notARepositoryShowsError`,
`cancellationThrowsCancelled`, `newSelectionCancelsPreviousDiscovery`.
