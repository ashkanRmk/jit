# P0.3 — `GitCore` primitives

## Behavior

- **`GitVersion`** parses `git version X.Y.Z[...]` including Apple (`2.39.5 (Apple Git-154)`) and
  Windows-style (`2.45.1.windows.1`) suffixes; comparable; `GitVersion.minimum == 2.39.0`.
- **`GitLocator`** returns the first usable candidate, by file existence only (it never runs anything):
  1. `JIT_GIT_PATH` (debug builds only), 2. bundled `Contents/Resources/git/bin/git` (absent until
  Phase 7), 3. user override (Phase 6, nil now), 4. `/opt/homebrew/bin/git`, `/usr/local/bin/git`,
  5. Apple's real Git: `<selected developer dir>/usr/bin/git` (developer dir from `DEVELOPER_DIR` or the
  `/var/db/xcode_select_link` symlink), else `/Library/Developer/CommandLineTools/usr/bin/git`. The
  `/usr/bin/git` shim is never returned (changed after review). Otherwise `gitNotFound`.
- **`ProcessRunner.run(_ spec:)`** launches an executable with an argv array via `posix_spawn`:
  explicit cwd (`posix_spawn_file_actions_addchdir`), stdin `/dev/null`, new session/process group
  (`POSIX_SPAWN_SETSID`, which also detaches from any controlling terminal so nothing can prompt on a
  tty), `POSIX_SPAWN_CLOEXEC_DEFAULT`, default signal dispositions and empty mask.
  - Environment is built from scratch: allowlisted parent vars (`HOME`, `USER`, `LOGNAME`, `TMPDIR`,
    `SSH_AUTH_SOCK`), minimal `PATH`, `LC_ALL=C`, `GIT_TERMINAL_PROMPT=0`, `GIT_ASKPASS`/`SSH_ASKPASS`
    = `/usr/bin/false`, `SSH_ASKPASS_REQUIRE=never`, `GIT_EDITOR`/`GIT_SEQUENCE_EDITOR`=`true`,
    `GIT_MERGE_AUTOEDIT=no`, `GIT_PAGER`/`PAGER`=`cat`; `GIT_OPTIONAL_LOCKS=0` for read commands; plus
    explicit per-engine overrides (used by GitTestKit and, later, per-invocation identity).
  - stdout/stderr: non-blocking pipes read by `DispatchSource` read sources; exit observed with a
    `DispatchSource` process source + `waitpid(WNOHANG)`. All on a per-command serial queue. No thread
    blocks; the awaiting task holds no thread (checked continuation).
  - Limits: stdout cap (bytes) → `outputTooLarge`, group killed. stderr keeps the last 64 KiB.
  - Timeout and Swift task cancellation → `SIGTERM` to the group, `SIGKILL` after 2 s.
  - After the main child exits, pipes are drained until EOF; if a leftover group member holds them
    open for 2 s it is killed.
  - Exit codes outside `spec.acceptedExitCodes` → `processFailed(exitCode:summary:detail:)`.
  - There is no API that takes a shell string.
- **`RepositoryDiscovery`** classifies a folder: regular / bare / linked worktree, top level, git dir,
  common dir, HEAD (branch / detached at SHA / unborn branch). Two `rev-parse` calls + `symbolic-ref`
  + `rev-parse --verify`. Timeout 15 s.
- **`GitCoreError`** cases carry a user-presentable `summary`; raw stderr becomes `detail` after
  credential-shaped URL parts are redacted.
- **`GitEngine`** actor: no I/O in `init`; `gitInfo()` locates Git and probes its version once (cached);
  `discoverRepository(at:)` checks the minimum version first.

## Failure cases

Not a repository; path missing; permission denied (cwd not enterable or Git reports it); dubious
ownership → `unsafeRepository` (never adds `safe.directory`); Git missing; Git too old; child ignores
SIGTERM; grandchild holding pipes; output over cap; cancellation before spawn; cancellation while
running; timeout.
