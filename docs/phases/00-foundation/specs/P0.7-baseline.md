# P0.7 — Baseline measurements

## Behavior
- `-JitBenchmarkLaunch`: the app measures kernel process start → first window key (fallback: root view
  appeared, when the app is never activated), prints `first_window_ms=<ms> trigger=<key|content>`, writes
  it to `$JIT_BENCHMARK_OUTPUT` if set, emits an os_signpost "Launch" interval, and quits.
  `-JitBenchmarkTrigger key` ignores the fallback.
- `scripts/benchmarks/launch.sh [--key] [runs]`, `scripts/benchmarks/idle.sh [label]` (env `JIT_OPEN`,
  `JIT_ACTIVATE`), `JitBench spawn-latency|discovery` — outputs JSON in `scripts/benchmarks/out/`.
- Release build only; environment recorded with every result (`docs/performance.md`).

## Failure cases
App never activated (recorded via trigger); path-valued launch arguments treated as files by AppKit (env
variables used instead); measurements needing root or a reboot are documented as user-run, not invented.
