# P0.5 — Foundation window calling `GitCore`

## Behavior
- One window (min 960×600) with the unified system toolbar (system Liquid Glass) holding one "Open…"
  button; ⌘O (File ▸ Open Repository…) and drag-and-drop of a folder do the same.
- Opaque `surface.canvas` content runs under the toolbar with the soft scroll-edge effect.
- `FoundationModel` (`@MainActor @Observable`): `empty | loading(showsIndicator) | loaded(info, git) |
  failed(url, error)`. A new selection cancels the running discovery; closing the window cancels too.
  The spinner appears only after 150 ms.
- Loaded card: kind eyebrow, name, top-level path (middle-truncated, selectable), branch / detached /
  unborn, full commit SHA, git dir, main repository (worktrees), Git version + source + executable.
- Error block: summary sentence, path, guidance per error (not a repo, permission, Git missing, Git too
  old, unsafe repository — Jit never adds `safe.directory`), redacted "Details", "Choose Another Folder…".
  Announced to VoiceOver.
- On quit, every live Git process group is killed (`ProcessRunner.terminateAllRunning()`).
- Debug-only launch arguments for repeatable checks: `-JitOpen`, `-JitAppearance`, `-JitShowGallery`,
  `-JitGallerySection`, `-JitSnapshot`, `-JitSnapshotWindow`, `-JitSnapshotDelay`.

## Verification
Real folders: this repository, a bare clone, a linked worktree, a fresh `git init`, a plain folder,
a `chmod 000` folder. Slow Git (`JIT_GIT_PATH` wrapper sleeping 5 s): the window keeps rendering and
shows the loading state. Screenshots in `../screenshots/`.
