## Process APIs verified

- `posix_spawn_file_actions_addchdir` is `API_AVAILABLE(macos(26.0))`; the `_np` variant is deprecated
  in 26.0. Jit uses `addchdir` (deployment target 26.0).
- `POSIX_SPAWN_SETSID` (0x0400), `POSIX_SPAWN_SETPGROUP`, `POSIX_SPAWN_CLOEXEC_DEFAULT` (0x4000),
  `POSIX_SPAWN_SETSIGDEF`, `POSIX_SPAWN_SETSIGMASK` are defined in `sys/spawn.h`.
- `swift-subprocess` current release **1.0.2** (tags 1.0.0 … 1.0.2). macOS 13+, no dependencies on
  Apple platforms. It supports `PlatformOptions.processGroupID`, `createSession`, a teardown sequence
  that can signal the process group, and `Environment.custom`. On Darwin it runs I/O through a dedicated
  kqueue **monitor pthread** plus a background-thread helper. Spike result in ADR-0005.

## Git behavior verified (Git 2.54.0)

- `rev-parse --show-toplevel` exits 128 ("must be run in a work tree") in a bare repository **and** when
  the cwd is inside `.git`. Discovery is therefore two calls: first
  `rev-parse --path-format=absolute --absolute-git-dir --git-common-dir --is-bare-repository --is-inside-work-tree`,
  then `--show-toplevel` only when inside a work tree.
- Unborn branch: `symbolic-ref -q HEAD` prints `refs/heads/<name>`, `rev-parse -q --verify HEAD^{commit}`
  exits 1.
- `GIT_TEST_ASSUME_DIFFERENT_OWNER=1` makes Git report "detected dubious ownership" — used in tests to
  exercise the `unsafeRepository` path with a real Git.
- Minimum Git version: see ADR-0006 Phase 0 addendum (2.39).

## Bundled Git feasibility (input to ADR-0019)

Recorded in `docs/release.md` → "Bundled Git feasibility". Summary: build from source with
`RUNTIME_PREFIX=YesPlease` so Git finds `libexec/git-core` relative to its binary; link HTTPS against the
system's `libcurl`/Security (macOS ships them) to avoid vendoring OpenSSL; sign every Mach-O in
`libexec/git-core` with the app's Developer ID and Hardened Runtime; ship the corresponding source (GPLv2).

## Risks found

| Risk | Mitigation |
|---|---|
| No signing identity on the machine | Ad-hoc signing for Phase 0–6; Developer ID in Phase 7. |
| `/usr/bin/git` shim pops the CLT install dialog when CLT is missing | Locator checks `CommandLineTools/usr/bin/git` or the selected developer dir's `usr/bin/git` by file existence before considering `/usr/bin/git`. |
| `swift-subprocess` keeps a monitor thread alive | Own `posix_spawn` wrapper (ADR-0005). |
| SDK is 27.2 but the target is 26.0 | Only `@available(macOS 26.0)` APIs; `effectIsInteractive` (27.0) avoided. Running on a real macOS 26 machine is not possible here — noted in progress.md. |
