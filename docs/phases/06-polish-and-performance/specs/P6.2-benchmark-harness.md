# P6.2 — Benchmark harness and synthetic repositories

## Behavior
- `scripts/benchmarks/gen-repos.sh` → `$JIT_BENCH_DIR` (default `~/Library/Caches/jit-bench/p6`):
  `linear-1k`, `branchy-10k` (200 branch refs, merge every 5th commit, 16 live features), `huge-100k`
  (1,000 branch refs, 500 tags), `many-files` (150 staged, 50 partially staged, 150 unstaged, 50 staged renames,
  100 untracked), `large-diff` (50,000-line file rewritten in 200 hunks + a 5 MB one-line file), `wide-tree`
  (50,000 tracked files). Built by `JitBench make-bench-repo` (GitTestKit `BenchRepo`, fast-import, fixed
  seeds/dates/identities). Idempotent: a manifest digest (refs + porcelain status) is checked; mismatch →
  warning, rebuild with `--force`.
- Scenarios (`scripts/benchmarks/scenarios/`): `launch-warm`, `launch-cold` (`sudo -n purge`, else
  `not-measured`), `idle.sh <0|1|5>` (restored session in a temp state dir), and `app-scenario.sh` for the
  in-app ones: `open-repo`, `graph-scroll`, `diff-switch`, `large-diff`, `many-files`, `multi-tab`,
  `open-close-loop`.
- `footprint.sh`, `network-idle.sh` (lsof + nettop), `idle.sh` (existing).
- `run-all.sh [--quick] [--no-idle] [--ci]` → `benchmarks/results/<date>-<sha>.json` + `-summary.md` (ignored by
  Git); compares against `scripts/benchmarks/baseline/reference.json`.
- `results.py collect|compare`, `compare.sh`: per-metric thresholds (ADR-0041); exit 1 on regression or a
  missing metric; `--loose` for CI.
- `JitBench micro`: lane layout 10k/100k (parse + layout + store), status parse (100k entries), diff parse
  (50k-line fixture), patch build (one line of that file); median/p90 after 3 warm-ups; retained bytes via
  `malloc_zone_statistics` (store size for lane layout). Uses `@_spi(Benchmarks) CoreBenchmarks`.
- `-JitOpaqueChrome YES`: Jit's own glass (tab strip, capsules, floating bars) renders as the Reduce
  Transparency opaque surface for glass-cost A/B. System chrome stays system.
- `instruments/trace.sh` + `signposts.py`: headless xctrace record + signpost interval extraction. The app is
  launched through `/usr/bin/env` because `xctrace --launch <app>` resolved the bundle ID to a stale Debug
  UI-test build.

## Tests
- `BenchRepoDeterminismTests` (linear-1k, many-files built twice → identical refs and status).
- `scripts/benchmarks/tests/test_results.py`: pass, regression (relative and absolute), loose mode, missing
  metric, improvement, line parsing. Run: `python3 -m unittest discover -s scripts/benchmarks/tests`.
