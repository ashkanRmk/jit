# P6.4–P6.6 — Startup, idle and memory (measured)

Each change cites the measurement that motivated it (reference Mac, release, `run-all.sh` scenarios).

| Change | Before → after | Evidence |
|---|---|---|
| Closed tabs deallocate (hosted SwiftUI views detached on close; weak cross-model closures) | open/close ×50: 531 MB peak / 411 MB settled → 157 / 66 MB; leaks 0 | `ClosedTabDeallocatesTests`, `leaks` |
| Snapshot token reads concurrent; one fingerprint per token; word-wise content hash | diff switch 63.5 → 43–51 ms (noisy machine) | trace: 7 sequential Git processes; `Fingerprint.read` 183 samples |
| Long lines laid out up to 10,000 characters | 5 MB-line diff footprint 1,218 → 204 MB | `vmmap`, `heap` (220 MB glyph advances) |
| Divider restore only when off | applyWidths 190 → 0 main-thread samples / 40 tab switches (latency unchanged) | Time Profiler |
| Accounts service created on first use | no Keychain/path monitor at launch | `LaunchWorkTests` |
| Reverted (no measurable effect): toolbar guards for title, tracking separator, profile capsule size | — | tab switch median 17.2 → 17.1 ms |

Launch needed no change (warm ≈ 255–265 ms, cold ≈ 233–236 ms; first window layout ≈ 60 ms dominates).
