# P6.10 — Accessibility

- Graph rows: label "Commit <sha>, <subject>, by <author>, <date>, <refs>, merge of N parents"; rotors
  Branches and Tags, Merge Commits, HEAD over loaded rows.
- Diff: one element per visible row; hunk/file rows are headings; rotors Changes (block starts) and Hunks;
  custom actions on changed lines: Select line, Extend selection to this line, Stage / Unstage / Discard selected
  lines (discard still asks for confirmation).
- Differentiate Without Color: +/− gutter glyphs; square / diamond status dots.
- Text size: View ▸ Larger / Smaller / Default Code Text (S, M, L, XL = 11, 12, 14, 16 pt) for code and diff.
- Increase Contrast / Reduce Transparency: existing token variants (ContrastTests) and opaque chrome (snapshots).
- Tests: `AccessibilityTests` (labels, headings, rotors, staging one line through actions only).
