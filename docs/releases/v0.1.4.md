# Jit 0.1.4 — test build

- The disk image now opens to a branded installer with the Jit wordmark, a Retina background, and a
  drag-to-Applications layout.
- Updates from Jit 0.1.3 use the same Ed25519 signing key. Jit verifies the signature and disk image
  before installing the update.

## Update or install

From **Jit 0.1.3**, open the bell, choose **Check for Updates**, then select **Install and Restart**.
For a fresh install or an upgrade from **0.1.2 or earlier**, download `Jit-0.1.4.dmg` and drag **Jit**
to **Applications**. About Jit should show **0.1.4 (14)**.

Jit is free and requires Apple silicon and macOS 26 or later. This test build is ad-hoc signed. If
macOS blocks first launch, open **System Settings → Privacy & Security → Open Anyway**.
