# Jit 0.0.5 — test build

The fifth test build: Jit can now update itself from GitHub Releases, Settings ▸ Accounts has a tab per
provider (including GitHub Enterprise), and the diff and right panel no longer flicker. Ad-hoc signed, not
notarized.

**Requirements:** macOS 26 or later on Apple silicon. Nothing else: Git 2.56.0 is included.

## What changed since 0.0.4
**Updates and change log (ADR-0051)**
- A bell at the top right of the window opens What's New with the change log; a badge shows when a newer
  release is known. Jit ▸ Check for Updates… opens the same sheet and asks GitHub.
- One setting: with **update automatically** on, Jit checks at most once a day, downloads a newer release,
  verifies it (checksum, signature, version) and installs it when you quit. Off (the default), Jit asks
  nothing until you check.

**Accounts**
- Settings ▸ Accounts has GitHub, GitHub Enterprise, GitLab and GitLab Self-Managed tabs. For a self-hosted
  server, enter the host and a token and press Connect: the token is checked, the server is added and the
  token goes into the Keychain in one step. Nothing is saved if it fails.
- Connected accounts show as cards with Check Now, Replace Token and Disconnect.

**Diff viewer**
- Switching files no longer flashes an empty diff: the previous file stays until the next one is ready.
- Esc closes the diff from the file list too, not only from the graph or the diff itself.
- The diff options — unified / side by side / file view, wrap, ignore whitespace, show whitespace, word
  highlighting, syntax highlighting — are remembered for every repository and tab.
- With wrap off, both halves of a side-by-side diff scroll sideways together; word highlights sit on the
  right line.

**Window and panels**
- The right panel keeps the shown commit until the next one loads (no flicker between commits).
- Unstaged, Staged and Conflicts are equal fixed-height cards that scroll their own files.
- The sidebar toggle stays beside the window controls across tabs; every repository opens the right panel
  at the same saved width.
- Action bar order: Fetch, Branch, Pull, Push, Stash, Pop, Terminal (the changes item is gone; the
  uncommitted-changes row shows it).

## Install
1. Open `Jit-0.0.5.dmg` and drag **Jit** to **Applications** (replace an older copy).
2. The DMG is not notarized. If you downloaded it, macOS blocks the first launch ("Apple could not verify
   “Jit”…"): click **Done**, then **System Settings → Privacy & Security → Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/Jit.app`. A DMG built on the same Mac opens normally.
3. Replacing another ad-hoc build can make macOS ask once whether Jit may use its saved Keychain items
   (tokens, SSH passphrases); choose **Always Allow**.

Help ▸ About should show "Version 0.0.5 (5, …)".

## Build it yourself
```bash
scripts/release/release.sh --version 0.0.5 --adhoc
```
Output: `build/release/0.0.5/Jit-0.0.5.dmg` (git-ignored), with `validation.txt` beside it.
