# Jit 0.1.7 — test build

- SSH remotes use the Mac’s SSH configuration and key selection when the active profile uses **System SSH settings**. Existing SSH clones can fetch with keys configured in `~/.ssh/config`.
- The right sidebar’s text and controls align to display pixels at fractional workspace zoom levels.
- In-app updates show a progress bar and percentage while downloading, followed by a verification status.

## Update or install

Open the bell in Jit, choose **Check for Updates**, then select **Install and Restart**. For a fresh install or an upgrade from **0.1.2 or earlier**, download `Jit-0.1.7.dmg` and drag **Jit** to **Applications**. About Jit should show **0.1.7 (17)**.

Jit requires Apple silicon and macOS 26 or later. This test build is ad-hoc signed. If macOS blocks first launch, open **System Settings → Privacy & Security → Open Anyway**.
