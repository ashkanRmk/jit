# Jit 1.0.0

A native macOS Git client — 100% Swift, Liquid Glass design, free.

**Requirements:** macOS 26 or later on Apple silicon. Nothing else: Git 2.56.0 is included.

## Install
1. Download `Jit-1.0.0.dmg` and check it: `shasum -a 256 ~/Downloads/Jit-1.0.0.dmg` must print
   `c33921805fd6510e099ac5d2e51bee7e8b4dbce3d7fb81a01e5ddd75eeba7fb4`.
2. Open the DMG and drag **Jit** to **Applications**.
3. **Jit is not notarized by Apple**, so the first launch is blocked ("Apple could not verify “Jit”…"). Click
   **Done**, then open **System Settings → Privacy & Security → Open Anyway** (or run
   `xattr -dr com.apple.quarantine /Applications/Jit.app`).

## Highlights
- Repository tabs; a fast, virtualized commit graph (100k+ commits)
- Native diff with file, hunk and line staging and safe discard (with recovery copies); blame
- Fetch, pull, push, clone, branches, merge, rebase, cherry-pick, revert, stash
- Three-way conflict resolver
- Profiles for identity and authentication (SSH, tokens, OAuth when configured), custom CAs and proxies;
  Jit never changes your global Git or SSH configuration
- ⌘K command palette, keyboard navigation, VoiceOver labels and rotors
- No telemetry, no background network, no auto-updater

## Known limitations
- Not notarized (see Install). There is no automatic update: check this page for new versions.
- GitHub/GitLab sign-in with OAuth is not configured in this build; use a personal access token or SSH.
- Apple silicon only.
