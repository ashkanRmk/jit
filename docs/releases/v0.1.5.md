# Jit 0.1.5 — test build

- The commit graph shows saved stashes above their base commits. Select a stash in the sidebar to
  jump to its graph row, then select a tracked file in the inspector to view its diff.
- The working-tree row now uses a `// WIP` label, a dotted graph node, and a count of changed files.
- The diff viewer can render Markdown, and workspace zoom keeps graph controls and the sidebar
  aligned.

## Update or install

From **Jit 0.1.3 or later**, open the bell, choose **Check for Updates**, then select **Install and
Restart**. For a fresh install or an upgrade from **0.1.2 or earlier**, download `Jit-0.1.5.dmg` and
drag **Jit** to **Applications**. About Jit should show **0.1.5 (15)**.

Jit is free and requires Apple silicon and macOS 26 or later. This test build is ad-hoc signed. If
macOS blocks first launch, open **System Settings → Privacy & Security → Open Anyway**.
