# Jit 0.0.9 — test build

Tag management, precise graph sizing, safe local branch cleanup, and sharp workspace zoom.

**Requirements:** macOS 26 or later on Apple silicon. Git 2.56.0 is included.

## What changed since 0.0.8

- Create lightweight or annotated tags, inspect tag objects and messages, and push an individual tag.
  Confirmed local deletion records recovery metadata; remote deletion checks the exact object lease
  and keeps the local tag.
- Drag graph columns to your chosen width. Long branch names truncate instead of moving the divider;
  widths persist across tabs and relaunches, with horizontal scrolling when needed.
- Fetch prunes stale remote-tracking branches. Each remote has a refresh action, and Fetch All Remotes
  refreshes every remote. The origin list reflects the last successful fetch, including when offline.
- Local branches without a known remote counterpart have a trash action with confirmation. Bulk cleanup
  refreshes all remotes and checks their live branches before listing merged local branches for approval.
  Current branches, branches checked out in other worktrees, unmerged branches, and branches still on a
  remote are kept. Failed remote checks stop cleanup; no remote branch is deleted.
- Zoom the workspace from 75% to 150% with **⌘+ / ⌘=**, **⌘−**, and **⌘0** or the View menu. The selected
  zoom persists. Fonts and SF Symbols render at their destination size to stay sharp, and small windows
  scroll to keep panels accessible. Code-only font sizing remains available separately.
- Correct SwiftUI pointer targets, text baselines, header sizing and split-pane bounds at enlarged sizes.

## Install

1. Open `Jit-0.0.9.dmg` and drag **Jit** to **Applications**, replacing the older copy.
2. This test build is ad-hoc signed and **not notarized**. If macOS blocks a downloaded first launch,
   click **Done**, then use **System Settings → Privacy & Security → Open Anyway**.
3. Replacing an ad-hoc build may prompt once for access to existing Keychain items; choose **Always Allow**
   if you want Jit to keep using its saved credentials.

Help → About should show version **0.0.9 (9)**.

## Build it yourself

```bash
scripts/release/release.sh --version 0.0.9 --adhoc
```

Artifacts and validation are written to `build/release/0.0.9/`.

## Known limitations

Ad-hoc signing; no notarization or stapling. Apple silicon only. One existing process-runner
thread-count test fails on this host as detailed above. Remote lists remain cached until a
successful fetch; the local trash hint uses that cache, while bulk cleanup verifies live remote branches.
Unmerged local branches require individual review. OAuth requires a configured client; personal access
tokens and SSH remain available. Clean-VM acceptance and a live VoiceOver walkthrough were not performed.
