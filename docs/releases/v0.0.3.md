# Jit 0.0.3 — test build

The third test build: a new action bar, the branch and profile in the sidebar, a more capable diff viewer and
reworked side panels. Ad-hoc signed, not notarized.

**Requirements:** macOS 26 or later on Apple silicon. Nothing else: Git 2.56.0 is included.

## What changed since 0.0.2
**Toolbar and action bar**
- A bar under the tabs holds the everyday commands — **Pull, Push, Fetch, Branch, Stash, Pop, Terminal** —
  as icons with their names, without button outlines. A click runs the main action; right-click Pull or
  Fetch for the other variants. When the pane is narrow the names drop first, then the last items move
  into `⋯`.
- The window toolbar is now only the sidebar toggle (a bare icon) and the tabs. Its items no longer move or
  disappear when the window is zoomed or resized.
- Removed: the "which branches the graph shows" menu (the graph shows all branches), the all-tabs chevron
  (use the Window menu) and the inspector toggle button (View ▸ Show Inspector, ⌥⌘0).
- Tabs and containers are a little squarer.

**Left sidebar**
- The current branch is at the top: click it for the branch list with a filter.
- Your Git profile and the Settings button are at the bottom.
- Section titles have icons (computer, cloud, tag, tray), the text is slightly larger and the containers are
  lighter, so the sidebar's glass shows through.

**Diff viewer**
- Opening a file's diff closes the left sidebar; Esc brings it back. Esc closes only the diff — the right
  panel and the selection stay.
- **Word wrap** (remembered), and buttons in the diff's bar for unified / side by side / full file, ignore
  whitespace and wrap. The icons are larger.
- **Stage File** / **Unstage File** in the diff of an uncommitted file.

**Uncommitted work**
- Unstaged comes first, Staged below it.
- Stage and Stage All are green, Unstage and Unstage All are red; a red trash button discards all unstaged
  changes (after the usual confirmation).
- File rows show the path without cutting the file name, and the Stage / Unstage button always fits.
- The commit box has larger summary and description fields with character counts and a warning for long
  lines, a full-width Commit button (⌘↩ from either field), and no "Committing as …" line when a profile is
  set.

**A commit in the right panel**
- The panel is wider by default and no longer scrolls as a whole: the message keeps its height (a long one
  scrolls inside) and the file list scrolls in its own container.
- The Tree view is a real tree: folders start closed and open with the plus button.

**Graph**
- Hover a commit to see, dimmed, the branch of the line it is on; it stays when the commit is selected.
- Time is shown as small tags at the end of the row where it changes ("7 hours ago", "yesterday") instead of
  a date on every row. The Date column can be shown again from the header's context menu.
- The graph column keeps its width while you scroll; drag its edge to set it.
- The expanded label strip is always opaque (labels could overlap and be unreadable).

**New-tab page:** the Jit logotype.

## Install
1. Open `Jit-0.0.3.dmg` and drag **Jit** to **Applications** (replace an older copy).
2. The DMG is not notarized. If you downloaded it, macOS blocks the first launch ("Apple could not verify
   “Jit”…"): click **Done**, then **System Settings → Privacy & Security → Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/Jit.app`. A DMG built on the same Mac opens normally.
3. Replacing another ad-hoc build can make macOS ask once whether Jit may use its saved Keychain items
   (tokens, SSH passphrases); choose **Always Allow**.

Help ▸ About should show "Version 0.0.3 (3, …)".

## Build it yourself
```bash
scripts/release/release.sh --version 0.0.3 --adhoc
```
Output: `build/release/0.0.3/Jit-0.0.3.dmg` (git-ignored), with `validation.txt` beside it.

## What was verified
- `scripts/build/lint.sh` clean; `scripts/build/test-app.sh` passes.
- `scripts/build/test-core.sh`: every suite passes except two tests, both on a Mac whose screen was locked
  during the run: `ProcessRunnerTests.timeoutKillsProcessGroup` (GitCore, not touched by this round) and
  `ClosedTabDeallocatesTests.closedRepositoryTabDeallocates`, which failed the same way on the unmodified
  0.0.2 sources in the same session. **They were not re-run with the screen unlocked.**
  New: `DiffWrapTests`, `RightPanelTests`, more cases in `GraphColumnsAndLabelsTests`. The graph, diff,
  new-tab and command-palette snapshots were re-recorded.
- The debug app was run against this repository and captured (dark and light): toolbar, action bar, sidebar
  header and footer, graph with time tags and the branch-of-line label, the side-by-side diff with the
  sidebar closed, the commit panel, the uncommitted-work panel and commit box, the new-tab logotype.

**Not verified:** anything that needs a real pointer or keyboard — right-click menus on Pull / Fetch, the
hover label following the pointer, dragging the graph column, Stage File and Discard All end to end, ⌘↩ from
inside the text fields, word wrap in the running app (unit-tested only), the profile popover opening from
the sidebar, the sidebar animation when a diff opens and closes, and window zoom / full screen. Benchmarks
and the §24 acceptance scenarios were not re-run.

## Known limitations
Same as [1.0.0](v1.0.0.md): not notarized, no automatic update, OAuth sign-in not configured (use a personal
access token or SSH), Apple silicon only. In a wrapped diff, wide characters (CJK, emoji) can run past the
edge of a line; the time tag covers the end of a long message on the rows where it shows.
