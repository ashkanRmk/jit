# Jit 0.0.6 — test build

Graph navigation, branch and tag workflows, and notification improvements.

## What changed since 0.0.5

- Changed-file arrow keys navigate files while retaining the selected commit.
- Commit rows use a hand cursor; column edges can be dragged from any row, and all rows redraw correctly.
- Expanded branch and tag labels stay above graph content without overlapping or stretching text.
- The checked-out branch has a distinct outline and checkmark. Opening a repository and completing Git actions reveal HEAD.
- Double-click branch labels to check out; checkout and other results appear in animated bottom-left notifications.
- Running operations replace the matching action icon with progress and disable other actions and tab switching.
- The inspector opens immediately without a laggy width animation.
- Create lightweight or annotated tags, optionally push immediately, and remember the push choice.
- Cmd-T creates a tag; Cmd-Shift-T copies the selected tag name. Cmd-P pushes and Cmd-Shift-P pulls the selected branch.
- New Tab moves to Option-Cmd-N; Reopen Closed Tab moves to Option-Cmd-Shift-T.
- Expanded branch menus include upstream management, fast-forward, merge/rebase, checkout, confirmed resets, local/remote deletion, detached worktrees, and patch export.
- Merge and empty commit patch export targets the selected commit correctly.
- File watcher startup runs off the UI thread so slow macOS registration does not freeze the window.

## Install

Open `Jit-0.0.6.dmg` and drag Jit to Applications, replacing the previous copy.
This build is ad-hoc signed and not notarized, following the existing test-build distribution policy.
Help → About should show version 0.0.6 (6).

## Build

```bash
scripts/release/release.sh --version 0.0.6 --adhoc
```

Artifacts and validation are written to `build/release/0.0.6/`.
