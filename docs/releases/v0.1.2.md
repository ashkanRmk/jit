# Jit 0.1.2 — test build

Plan an interactive rebase in Jit or edit a single commit directly from the graph.

- **Interactive rebase.** Use **Branch → Interactive Rebase…** or right-click a commit and choose **Interactive Rebase from Here…**. Reorder commits and choose Pick, Reword, Edit, Squash, Fixup, or Drop. Review the resulting history before running the plan.
- **Edit or drop a commit.** Right-click a commit and choose **Edit Message…** to rewrite its message, or **Drop Commit…** to remove it from the current branch's history. Jit shows the affected commits and a recovery reference before you confirm.
- Jit warns when selected commits are reachable from tracked remote branches. During a rebase, you can resolve conflicts, continue, skip, or abort from the operation controls.

Interactive rebase supports linear ranges of up to 500 commits. History rewrites require a clean tracked working tree and an attached branch.

## Update or install

From Jit 0.1.1, open the toolbar bell, choose **Check for Updates**, then **Install and Restart**.

For a fresh install, open `Jit-0.1.2.dmg` and drag **Jit** to **Applications**. The app requires macOS 26 or later on Apple silicon and includes Git 2.56.0. This test build is ad-hoc signed. If macOS blocks the first launch, click **Done**, then open **System Settings → Privacy & Security → Open Anyway**.

**About Jit** should show **0.1.2 (12)**.
