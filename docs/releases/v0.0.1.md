# Jit 0.0.1 — test build

An internal test build of the V1 feature set, for trying the installed app before the public 1.0.0. It is
**not published**: build it locally (below). Same code as `main` at `e99efe6` plus the version change.

**Requirements:** macOS 26 or later on Apple silicon. Nothing else: Git 2.56.0 is included.

## Build
```bash
scripts/release/release.sh --version 0.0.1 --adhoc
```
Output: `build/release/0.0.1/Jit-0.0.1.dmg` (git-ignored), with `validation.txt` beside it.

## Install
1. Open `build/release/0.0.1/Jit-0.0.1.dmg` and drag **Jit** to **Applications** (replace an older copy).
2. A DMG built on the same Mac is not quarantined, so Jit opens normally. If the DMG was downloaded or
   copied from another Mac, macOS blocks the first launch ("Apple could not verify “Jit”…"): click **Done**,
   then **System Settings → Privacy & Security → Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/Jit.app`.
3. Replacing another ad-hoc build can make macOS ask once whether Jit may use its saved Keychain items
   (tokens, SSH passphrases); choose **Always Allow**.

Help ▸ About should show "Version 0.0.1 (1, …)".
