# Jit 0.0.4 — test build

The fourth test build: a fix for tabs vanishing from the toolbar, a simpler action bar, a flat diff header
and restyled side panels. Ad-hoc signed, not notarized.

**Requirements:** macOS 26 or later on Apple silicon. Nothing else: Git 2.56.0 is included.

## What changed since 0.0.3
**Fixes**
- The tabs no longer disappear from the toolbar (leaving only a `»` button) after switching tabs or resizing.
- A new repository tab opens with the sidebar and right-panel widths you last chose.

**Action bar**
- Pull, Push, Fetch, Branch, Stash, Pop, Terminal, the changes count and Search are one centred row of
  plain tools with their names: no glass, no container, slightly smaller.

**Diff viewer**
- A flat two-row header: the file's path with Stage File and Close; below it the side on the left,
  **File View | Diff View** in the middle and the tools on the right (Blame, previous / next change, unified
  / side by side, ignore whitespace, wrap, find, options).
- If the diff text looks large, that is the saved text size: View ▸ Smaller Code Text (⌘−) or Reset.

**Uncommitted work**
- "N file changes on `branch`" at the top with Discard All beside it; a labelled Path | Tree switch.
- "Unstaged Files (n)" and "Staged Files (n)" with outlined **Stage All Changes** / **Unstage All Changes**.
- Rows show how the file changed as an icon; the hovered or selected row has an outlined **Stage File** /
  **Unstage File** button.

**A commit in the right panel**
- `commit: <sha>`, the message in its own box, the author with "authored <date>" and the parent beside it,
  then the files with a summary ("4 modified, 1 added") and a labelled Path | Tree switch.

**Sidebar:** the Jit logotype at the top right.

**Graph:** the branch-of-a-line label is dimmer, so it is not mistaken for a real label.

## Install
1. Open `Jit-0.0.4.dmg` and drag **Jit** to **Applications** (replace an older copy).
2. The DMG is not notarized. If you downloaded it, macOS blocks the first launch ("Apple could not verify
   “Jit”…"): click **Done**, then **System Settings → Privacy & Security → Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/Jit.app`. A DMG built on the same Mac opens normally.
3. Replacing another ad-hoc build can make macOS ask once whether Jit may use its saved Keychain items
   (tokens, SSH passphrases); choose **Always Allow**.

Help ▸ About should show "Version 0.0.4 (4, …)".

## Build it yourself
```bash
scripts/release/release.sh --version 0.0.4 --adhoc
```
Output: `build/release/0.0.4/Jit-0.0.4.dmg` (git-ignored), with `validation.txt` beside it.

## What was verified
- `scripts/build/lint.sh` clean; `scripts/build/test-app.sh` passes. `scripts/build/test-core.sh`: Services
  (210 tests), Features (168) and DesignSystem (15) pass. GitCore (396) passes except one timing budget,
  `RefsTests.refs10kBranchesUnder100ms`, which failed in 2 of 4 runs on a busy machine; GitCore was not
  changed in this round.
- `ClosedTabDeallocatesTests` failed intermittently when the suites ran in parallel — also on the 0.0.3
  sources (1 of 3 runs). The tab is released, only later than the test's fixed 500 ms pause; the test now
  waits for the release (up to 5 s) and passed 5 of 5 full runs.
- The diff, graph, new-tab and command-palette snapshots were re-recorded.
- The debug app was run against this repository and captured: the toolbar with tabs and the sidebar
  logotype, the centred action bar, the commit panel, the uncommitted-work panel, the diff header (light).

**Not verified:** switching between several tabs and zooming the window in the running app (the fix was
checked with one tab), the diff header on an uncommitted file (Stage File), dark appearance of the diff
header, narrow-pane fallbacks, new-tab panel widths, and anything needing a pointer (hover buttons, menus).
Benchmarks and the §24 acceptance scenarios were not re-run.
