# Jit 0.1.3 — test build

- In-app updates use a signed release manifest. Jit verifies its signature and the disk image before
  mounting or installing it. Failed verification leaves your current app in place.
- Jit remains free and open source. Update checks are available in **What's New**. Automatic updates
  remain opt-in under **Settings → General**.

## Update from 0.1.2 or earlier

Install 0.1.3 manually to get the update verification key. Quit Jit, download `Jit-0.1.3.dmg`, verify the
download using the [release guide](https://github.com/ashkanRmk/jit/blob/0.1.3/docs/release.md#publishing-owner-approval-required), and replace Jit in
Applications. About Jit should show **0.1.3 (13)**. Future signed updates can be installed from Jit.

The app requires Apple silicon and macOS 26 or later. This test build is ad-hoc signed. If macOS
blocks first launch, click **Done**, then open **System Settings → Privacy & Security → Open Anyway**.
