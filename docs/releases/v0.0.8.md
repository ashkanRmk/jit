# Jit 0.0.8 — test build

Reset previews, keep mode, and stash-first recovery.

**Requirements:** macOS 26 or later on Apple silicon. Git 2.56.0 is included.

## What changed since 0.0.7

- Graph and Reflog reset menus now offer **Soft, Mixed, Keep, and Hard** with a preview before confirmation.
- Inspect tracked local changes, commits leaving the current branch, unreachable commit counts and
  subjects, published-history warnings, and a copyable previous HEAD.
- **Keep** preserves local changes and refuses the reset if they conflict with the target commit.
- Dirty hard resets default to **Stash local changes first**, including untracked files. The stash uses
  the active profile; if stashing fails, reset does not run.
- Stash and reset run as one serialized writer operation. A later failure retains the stash and reports
  its exact SHA. Successful resets show both the previous HEAD and saved stash for recovery.
- Preview confirmation is bound to the repository, target, mode, stash choice, refs, index and local file
  contents. A changed repository requires a fresh preview.
- Hard and keep reset refuse untracked, ignored or directory paths that Git could overwrite. Submodule
  working files are never reset recursively, even when Git configuration requests it.

Recover committed history by creating a branch from the previous HEAD in **Reflog**, then restore the
saved changes from **Stashes** on that branch. Git-pruned objects and local edits discarded without a
stash cannot be recovered by the recovery journal.

## Install

1. Open `Jit-0.0.8.dmg` and drag **Jit** to **Applications**, replacing the older copy.
2. This test build is ad-hoc signed and **not notarized**. If macOS blocks a downloaded first launch,
   click **Done**, then use **System Settings → Privacy & Security → Open Anyway**.
3. Replacing an ad-hoc build may prompt once for access to existing Keychain items; choose **Always Allow**
   if you want Jit to keep using its saved credentials.

Help → About should show version **0.0.8 (8)**.

## Build it yourself

```bash
scripts/release/release.sh --version 0.0.8 --adhoc
```

Artifacts and validation are written to `build/release/0.0.8/`.

## Known limitations

Ad-hoc signing; no notarization or stapling. Apple silicon only. Hard/keep reset refuses hidden index
flags; stash-first cannot save dirty submodules, nested repositories or special files. Existing Stashes
Apply uses Git's default apply behavior; the original staged content remains in the stash's index parent.
OAuth requires a configured client; personal access tokens and SSH remain available. Clean-VM acceptance
and a live VoiceOver walkthrough were not performed for this release.
