# Jit 0.1.1 — test build

- **Install and Restart** closes **What's New** before restarting. This fixes a stall where the open sheet could keep Jit from quitting after the download.
- The toolbar bell loads missing or day-old changelog entries when you open it. This works with automatic updates turned off.
- With automatic updates on, an explicit update check also prepares the download for installation on quit.

## Updating from Jit 0.1.0

1. Open the bell and choose **Check for Updates**.
2. Choose **Install and Restart**. If Jit 0.1.0 stays open and says the update is ready, click **Done**, quit Jit, and open it again.
3. **About Jit** should show **0.1.1 (11)**.

## Installing from the DMG

Requires macOS 26 or later on Apple silicon. Git 2.56.0 is included.

Drag **Jit** from the DMG into **Applications**. This test build is ad-hoc signed. If macOS blocks the first launch, click **Done**, then open **System Settings → Privacy & Security → Open Anyway**.

[Download the prerelease and checksums](https://github.com/ashkanRmk/jit/releases/tag/0.1.1)
