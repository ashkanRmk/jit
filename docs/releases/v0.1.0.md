# Jit 0.1.0 — test build

Sign in to GitHub.com and GitLab.com from **Settings → Accounts**. Connect an account to browse private repositories, then link it to a profile to clone over HTTPS.

- GitHub uses a device code. Click **Copy Code** in Jit, then paste the code into GitHub and approve access.
- GitLab uses browser authorization. This release fixes a crash when the browser returns to Jit.
- Signing in again with the same provider account keeps its local entry and profile links.

## Install

Requires macOS 26 or later on Apple silicon. The app includes Git 2.56.0.

1. Open `Jit-0.1.0.dmg` and drag **Jit** to **Applications**.
2. This test build is ad-hoc signed and has no notarization ticket. If macOS blocks the first launch,
   click **Done**, then open **System Settings → Privacy & Security → Open Anyway**.
3. macOS may ask for permission to use Jit's existing Keychain items after updating. Choose **Always Allow**
   if you want Jit to keep using its saved credentials.

**About Jit** should show **0.1.0 (10)**.

## Verification

Live checks covered both browser sign-in flows, listing repositories, and cloning a private repository
over HTTPS on each provider with its connected OAuth account. The account and OAuth tests cover repeat
sign-in, renamed accounts, and concurrent sign-ins.
