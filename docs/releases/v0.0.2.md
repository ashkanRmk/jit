# Jit 0.0.2 — test build

The second test build: V1 plus a round of graph, panel and tab polish. Ad-hoc signed, not notarized.

**Requirements:** macOS 26 or later on Apple silicon. Nothing else: Git 2.56.0 is included.

## What changed since 0.0.1
**Commit graph**
- Ref labels show where a branch lives with icons instead of `⇄ origin` / `origin/`: a computer for local,
  a cloud for remote, both when the branch is in both places.
- Hover the Branch / Tag column to see every label of the row in full (branches and tags together); the
  labels slide open over the row. Hover the cloud for the full remote name (`origin/main`).
- The node shows the author's picture when Gravatar has one, initials otherwise. Hover a node for the
  author's name, email and the date.
- The table has a header: drag a column to reorder it, drag an edge to resize it, right-click the header to
  show or hide columns (or reset them). The arrangement is remembered.
- The search field is a magnifier button until you use it (click or ⌘F), so the command bar fits beside an
  open inspector.

**Diff**
- A file's diff opens in the centre of the window, over the graph. Esc or its close button returns to the
  graph. View ▸ Focus Diff became **Close Diff** (⌥⌘↩).

**Side panels**
- Every section sits in its own container: message, people, commit facts and files in the right panel;
  Staged / Unstaged / Conflicts in the working-directory panel; Local / Remote / Tags / Stashes in the left one.
- The right panel shows the author's (and committer's) picture.
- File rows never cut the file name: the folders in front shorten in the middle first.

**Fixes**
- Selecting a commit slides the right panel in instead of making it appear at once.
- Closing a tab no longer slides it behind its neighbour first.

**New setting:** Settings ▸ General ▸ *Show author pictures from Gravatar* (on by default). Jit asks
gravatar.com for a picture using a SHA-256 hash of the author's email, only for commits on screen, once per
author (ADR-0050). Switch it off to make no such request.

## Install
1. Open `Jit-0.0.2.dmg` and drag **Jit** to **Applications** (replace an older copy).
2. The DMG is not notarized. If you downloaded it, macOS blocks the first launch ("Apple could not verify
   “Jit”…"): click **Done**, then **System Settings → Privacy & Security → Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/Jit.app`. A DMG built on the same Mac opens normally.
3. Replacing another ad-hoc build can make macOS ask once whether Jit may use its saved Keychain items
   (tokens, SSH passphrases); choose **Always Allow**.

Help ▸ About should show "Version 0.0.2 (2, …)".

## Build it yourself
```bash
scripts/release/release.sh --version 0.0.2 --adhoc
```
Output: `build/release/0.0.2/Jit-0.0.2.dmg` (git-ignored), with `validation.txt` beside it.

## What was verified
- `scripts/build/test-core.sh`: all suites pass after the change (one run had a single unrelated failure,
  `ProcessRunnerTests.noThreadBlockedWhileWaiting`, a thread-count bound that passed when re-run).
  New: `GraphColumnsAndLabelsTests`, `AvatarStoreTests`; the three `graph-*` snapshots were re-recorded and
  reviewed. `scripts/build/test-app.sh` exit 0; `scripts/build/lint.sh` clean.
- The debug app was run against a small repository (local, remote-only and local+upstream branches, tags,
  staged and untracked files) and captured in light and dark: labels and icons, the hover strip
  (`-JitGraphHoverRow`), the header and columns, the centre-pane diff (`-JitInspectorOpenFile`), the three
  panels' containers.

**Not verified:** anything that needs a real pointer or a live network — dragging headers to reorder and
resize, the hover strip following the pointer, the tab-close and inspector animations in motion, and an
actual Gravatar download (the store is tested with a stub fetcher; the test repositories' authors have no
Gravatar). Benchmarks and the §24 acceptance scenarios were not re-run.

## Known limitations
Same as [1.0.0](v1.0.0.md): not notarized, no automatic update, OAuth sign-in not configured (use a personal
access token or SSH), Apple silicon only.
