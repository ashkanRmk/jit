# Jit 0.0.7 — test build

Reflog explorer, lost-commit recovery, and graph-label fixes.

**Requirements:** macOS 26 or later on Apple silicon. Git 2.56.0 is included.

## What changed since 0.0.6

- Open **Repository → Reflog**, choose Reflog in the action bar, or search for it with **⌘K**.
- Inspect HEAD or any local branch's reflog with action labels, event dates, commit details, pagination
  and unreachable-commit markers. Arrow keys navigate the list.
- **Find Lost Commits** searches on demand for commits no longer reachable from HEAD or a reference,
  including possible dropped stashes. The search shows progress and supports cancellation.
- Recover a commit into a new branch without checking it out by default. Compare with the current
  commit, copy its SHA, cherry-pick, or use the existing confirmed reset actions.
- **Show in Graph** temporarily includes a lost commit with dashed tip edges. It creates no Git ref
  and preserves saved graph filters.
- Saved recovery points retain previous committed states from Jit operations, including older stash
  deletions that leave the stash tip unchanged. Recovery always uses an exact commit ID.
- Branch labels remain visible along graph lines, and graph search controls no longer overlap.

Git-pruned objects and discarded uncommitted edits cannot be restored from recovery metadata.
Lost-commit results are limited to 2,000, with a visible notice; stash identification is a heuristic.

## Install

1. Open `Jit-0.0.7.dmg` and drag **Jit** to **Applications**, replacing the older copy.
2. This test build is ad-hoc signed and **not notarized**. If macOS blocks a downloaded first launch,
   click **Done**, then use **System Settings → Privacy & Security → Open Anyway**.
3. Replacing an ad-hoc build may prompt once for access to existing Keychain items; choose **Always Allow**
   if you want Jit to keep using its saved credentials.

Help → About should show version **0.0.7 (7)**.

## Build it yourself

```bash
scripts/release/release.sh --version 0.0.7 --adhoc
```

Artifacts and validation are written to `build/release/0.0.7/`.

## Known limitations

Ad-hoc signing; no notarization or stapling. Apple silicon only. OAuth requires a configured client;
personal access tokens and SSH remain available. Clean-VM acceptance and a live VoiceOver walkthrough
were not performed for this release.
